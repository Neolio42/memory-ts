PATTERN: Server component wrapper for metadata on client-heavy pages

WHEN: Any Next.js App Router page that needs both `export const metadata` AND client hooks (useState, useEffect, fetch)

WHY: `export const metadata` only works in server components. Pages using `"use client"` can't export metadata.

IMPLEMENTATION:
1. Create `app/[route]/PageClient.tsx` — move all client code here with `"use client"` directive
2. Rewrite `app/[route]/page.tsx` as server component:
```typescript
import { getSEOTags } from "@/libs/seo";
import Layout from "@/components/Layout";
import PageClient from "./PageClient";

export const metadata = getSEOTags({ ... });

export default function Page() {
  return <Layout><PageClient /></Layout>;
}
```

EXAMPLE: app/download/page.tsx + app/download/DownloadClient.tsx

GOTCHA: Don't add `<Layout>` in the client component — it belongs in the server wrapper
