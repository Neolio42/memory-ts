PATTERN: Atomic LWW for complex types
WHAT: transcription.snippets (Record<string, string>) and transcription.custom_vocabulary (string[]) are synced as single atomic values under LWW — desktop sends the complete object, server replaces if timestamp is newer.
WHY: Previous per-key dot-notation approach (e.g., 'transcription.snippets.greeting') broke on special characters in snippet keys. Union merge for custom_vocabulary made removals impossible.
IMPLICATION: Desktop must always send the full snippets object / full vocabulary array when updating — partial updates not supported for these fields.
ZOD: z.record(z.string()).strict() for snippets, z.array(z.string()) for vocabulary
ADMIN FIELD_CONFIG: type: 'record' for snippets, type: 'string[]' for vocabulary
