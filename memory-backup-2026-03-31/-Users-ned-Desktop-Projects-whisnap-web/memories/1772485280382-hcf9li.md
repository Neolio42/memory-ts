WHAT: API key locations for local LLM testing
WHERE:
- GROQ_API_KEY → root .env.local
- OPENAI_API_KEY → root .env.local
- GEMINI_API_KEY → api/.env (provider expects GOOGLE_AI_API_KEY)
HOW: In integration tests, load both env files and remap:
```typescript
require('dotenv').config({ path: path.join(__dirname, '../../../.env.local') });
require('dotenv').config({ path: path.join(__dirname, '../../.env') });
if (process.env.GEMINI_API_KEY && !process.env.GOOGLE_AI_API_KEY) {
  process.env.GOOGLE_AI_API_KEY = process.env.GEMINI_API_KEY;
}
```
GOTCHA: The Gemini provider reads GOOGLE_AI_API_KEY, not GEMINI_API_KEY — if tests fail with 'not configured' check this mapping
