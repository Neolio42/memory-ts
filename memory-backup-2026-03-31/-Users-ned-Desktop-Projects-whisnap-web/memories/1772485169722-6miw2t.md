PATTERN: All learning side-effects (vocab learning, fingerprint counting, fingerprint generation) run fire-and-forget after saveToDatabase — they NEVER block the transcription response.

WHERE: api/src/services/unified-processor.ts — `runLearningHooks()` method

HOW:
```typescript
private runLearningHooks(input: ProcessingInput, rawTranscript: string, llmOutput: string): void {
  // Vocab learning
  learnFromTranscription(...).catch(err => logger.warn('Vocab learning failed', err));
  
  // Style fingerprint  
  if (input.bundleId) {
    incrementTranscriptionCount(...).then(count => {
      if (shouldGenerateFingerprint(count)) {
        generateStyleFingerprint(...).catch(...);
      }
    }).catch(...);
  }
}
```

WHY: Learning failures must never degrade transcription quality. User gets their result immediately; learning happens in background.

CALLED: After saveToDatabase in both processInternal and processStreamingResult.
