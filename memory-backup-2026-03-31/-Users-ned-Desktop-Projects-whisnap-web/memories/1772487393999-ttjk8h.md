DECISION: Replace .passthrough() Zod schema with strict allowlist of exactly 11 snake_case field paths. Unknown fields → 400 error. No normalization, no camelCase acceptance.

CANONICAL FIELD LIST (the only fields server accepts):
- model.model_id
- audio_processing.audio_quality_preset
- ui.show_progress_banner
- system.launch_at_login
- system.keep_running_in_background
- transcription.auto_paste
- transcription.sound_effects_enabled
- transcription.sound_effects_volume
- transcription.mute_media_during_recording
- transcription.custom_vocabulary
- transcription.snippets

KEY DECISIONS:
- snippets: atomic LWW (whole object synced at once, NOT per-key dot-notation like transcription.snippets.<key>)
- custom_vocabulary: atomic LWW (whole array synced at once, NOT union merge)
- volume stored as 0-100 integer
- snippet keys lowercased on ingest for deduplication
- system section is NEW (didn't exist before)

REMOVED FROM SYNC (intentionally):
- ui.theme_mode (going full dark)
- transcription.language (hidden V1)
- transcription.translate_to_english (hidden V1)
- transcription.copy_to_clipboard (removed from app)

REJECTED APPROACHES:
- Per-key snippet tracking via transcription.snippets.<key> dot notation (breaks if key contains dots)
- Union merge for custom_vocabulary (makes deletion impossible without special mechanism)
- Server-side camelCase normalization (adds complexity, better to fix at source)
