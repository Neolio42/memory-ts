WHAT: Generate QR codes programmatically using Node.js qrcode npm package
HOW: Install with `npm install qrcode`, then use QRCode.toFile('output.png', 'https://url.com') or QRCode.toString for terminal output
WHY: Quick cross-platform QR generation without external services
GOTCHA: Package is 'qrcode' (not 'qr-code' or 'qrcode-generator') - this is the most commonly used Node.js QR library
