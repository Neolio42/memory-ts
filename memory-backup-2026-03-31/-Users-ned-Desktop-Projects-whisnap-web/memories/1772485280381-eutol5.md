SYMPTOM: 'dokr'→'docker' (dist=2, threshold=2) rejected. 'jra'→'JIRA' rejected by short-word check.
CAUSE: Edit distance used strict < so equal-threshold matches were rejected. Short-word check didn't exempt acronyms.
FIX:
1. Edit distance: `dist <= Math.min(Math.ceil(len * 0.3), 4)` (changed < to <=)
2. Short-word acronym exemption:
```typescript
if (corrected.length <= 4 && !/^[A-Z]{2,}$/.test(corrected)) {
  return true; // reject
}
// ALL CAPS (JIRA, API, AWS) pass through to full check
```
GOTCHA: 4-char ALL CAPS strings (JIRA, GDPR, HTTP) must NOT be rejected by the short-word guard — they're real acronyms that need edit distance checking
