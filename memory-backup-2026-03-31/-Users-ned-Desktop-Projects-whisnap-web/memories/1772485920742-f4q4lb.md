PRINCIPLE: The product is a megaphone — it makes the user's voice cleaner and louder without changing who they are. Not an AI secretary, not a rewriter.

THREE PILLARS AGREED ON:
1. Vocabulary auto-learning — learns proper nouns/tech terms from ASR vs LLM diffs, zero config
2. Destination profiles — format by bundle ID (email looks like email, Slack looks like Slack, code looks like code)
3. Style fingerprinting — after N uses per app, captures user's actual writing voice silently

WHAT WAS REJECTED:
- Identity/profile system (user: 'your translator doesn't need everything about you')
- Relationship awareness per recipient (too complex, v2 at best)
- Temporal/task awareness systems (overengineering)
- Manual vocabulary management (replaced by auto-learning)
- Mode switching UI (replaced by bundle ID lookup)

THE MOAT: Switching to a competitor means starting from zero. Vocab, format, voice — all learned from usage, none of it transferable.
