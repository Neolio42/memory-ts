DECISION: bundleId is the foundational addition that makes all cloud mode features possible.

CURRENT STATE: bundleId doesn't exist anywhere in the codebase — not in TranscriptionOptions (HTTP or WebSocket), not in TranscriptionHistory, not in any model.

WHAT IT UNLOCKS:
- Destination profile lookup → format instructions per app
- Style fingerprint scoping → voice preservation per app
- Vocabulary context → per-app term weighting
- Future: per-app context (thread, code, channel history)

DESKTOP CONTRACT (minimal):
```typescript
interface AppContext {
  bundleId: string;         // REQUIRED — the key for everything
  appName?: string;         // Display/logging
  windowTitle?: string;     // Email subject, Slack channel, etc.
  threadContext?: string;   // Email thread, Slack history above cursor
  fileLanguage?: string;    // 'python', 'typescript' for code editors
  cursorContext?: string;   // Surrounding code lines
}
```

PHASE 1 WORK: Add bundleId to TranscriptionOptions schema (HTTP + WebSocket), pass through pipeline, store on TranscriptionHistory. No behavior change yet — just plumbing.
