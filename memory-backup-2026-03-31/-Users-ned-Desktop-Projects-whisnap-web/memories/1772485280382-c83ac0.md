WHAT: isLikelySpecialTerm() misses all-lowercase technical tools
WHY: The heuristic checks for camelCase, PascalCase, ALL_CAPS, hyphens, dots, underscores, mixed alphanumeric, slash paths, @mentions, #tags, :: namespaces, URL fragments — but 'kubectl', 'terraform', 'nginx' have none of these signals
IMPACT: These terms get filtered out as common corrections even when the user consistently says them
WORKAROUND: Users must add these to custom_vocabulary manually
FUTURE FIX OPTIONS:
- Curated list of common DevOps/CLI tools
- If a term appears in raw transcript AND LLM transcript identically but lowercase, treat as confirmed special term
- Track correction frequency — if ASR always says 'cube cuddle' → 'kubectl', learn it after N occurrences
