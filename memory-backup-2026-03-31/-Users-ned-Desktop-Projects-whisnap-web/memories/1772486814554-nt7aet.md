PREVENT: These false claims were found and fixed — never reintroduce:

1. aggregateRating (4.8 stars, 12 reviews) — REMOVED from libs/seo.tsx global template, pricing/page.tsx, download/layout.tsx, speech-to-text-mac/page.tsx. Google can manually penalize fabricated ratings.

2. HIPAA/GDPR compliance — REMOVED from use-cases/meeting-notes. Whisnap is NOT certified for these. Say 'sensitive discussions' not 'regulated industries (HIPAA, GDPR)'.

3. 'Priority support' — does NOT exist as a product feature. Removed from meeting-notes page.

4. GPT-4/Claude/Deepgram/AssemblyAI as user-facing model choices — REMOVED. Cloud Mode is abstracted; users don't pick these. Backend implementation detail, not a selling point.

5. WebSocket streaming / real-time API features — REMOVED from stripe/cancel page. These are backend capabilities, not what Mac app users experience.

6. Pricing: always $10/month. The schema/metadata mistakenly had $9 — that was wrong. PricingWhisnap.tsx renders $10.
