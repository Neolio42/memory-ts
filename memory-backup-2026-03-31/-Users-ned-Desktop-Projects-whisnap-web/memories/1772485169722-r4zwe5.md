WHAT: Word-level diff engine between raw ASR output and LLM-corrected output, extracting terms the LLM consistently corrects to — these become the user's learned vocabulary.

WHERE: api/src/services/vocab-learner.ts

HOW:
1. `extractVocabCandidates(rawTranscript, llmOutput)` — tokenizes both, finds LLM words not in raw, finds nearest raw word by edit distance (threshold: 40% of word length), applies filters
2. `isLikelySpecialTerm(word)` — keeps: camelCase, PascalCase, ALL CAPS 2+ chars, mixed alphanumeric, hyphens/dots/underscores, slash paths, @mentions, namespaces (::), hash tags
3. `isCommonCorrection(raw, corrected)` — rejects: same word different case, homophones, common English words, inflections (plural/tense), contractions, short typos (≤4 chars, edit distance 1), numeric formatting, common prefix changes
4. `learnFromTranscription(userId, raw, llm, bundleId?)` — fire-and-forget upsert to LearnedVocabulary
5. `getLearnedVocabulary(userId, bundleId?)` — returns terms with occurrences≥2, merges global + app-specific, cap 100

WHY: Separates auto-learned vocab from user's manual custom_vocabulary — merged at prompt time, never pollutes settings. Occurrence threshold of 2 is conservative.

GOTCHA: common-words filter is currently dead code (see related bug). Also rawVariants grows unbounded (see related bug).
