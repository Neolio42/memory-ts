SYMPTOM: ESLint `react/no-unescaped-entities` errors on apostrophes (`'`) and quotes (`"`) inside JSX text content across many files — build fails with hundreds of errors

CAUSE: JSX text content between tags requires HTML entities for `'`, `"`, `>`, `<`

FIX: Bulk Node.js script targeting JSX text nodes:
```javascript
const fs = require('fs');
const files = [
  'app/use-cases/voice-notes/page.tsx',
  // ... all affected files
];
files.forEach(file => {
  let content = fs.readFileSync(file, 'utf8');
  content = content.replace(/>([^<]*)</g, (match, textContent) => {
    const fixed = textContent
      .replace(/(\w)'(\w)/g, '$1&apos;$2')  // contractions: don't, you're
      .replace(/(\w)'s/g, '$1&apos;s')       // possessives: Whisnap's
      .replace(/(\w)' /g, '$1&apos; ')       // trailing apostrophes
      .replace(/ '(\w)/g, ' &apos;$1')       // leading apostrophes
      .replace(/"([^"]*)"]/g, '&quot;$1&quot;'); // quoted strings
    return '>' + fixed + '<';
  });
  fs.writeFileSync(file, content);
});
```

PREVENT: When AI generates page content with prose text, run this script before build, or use a template that avoids contractions
