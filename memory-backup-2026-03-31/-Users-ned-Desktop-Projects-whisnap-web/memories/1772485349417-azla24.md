DECISION: Do not implement edit tracking in current sprint. Ship v1 (raw transcript learning) first.

OPTIONS CONSIDERED:
1. Immediate send detection (cmd+V → Enter = accepted)
2. Before/after snapshot diff
3. Keystroke counting
4. AX value change observer (macOS only)

REASONING:
- No data yet to know if it's needed — ship first, measure user satisfaction
- iOS has no equivalent to macOS AX APIs — would require two parallel feedback systems
- Lightweight v2 step: just add `wasEdited: boolean` to TranscriptionHistory. Desktop already knows if user pasted+immediately-sent vs pasted+kept-typing. One event, no snapshotting, cross-platform.

REVISIT WHEN: Users complain style isn't adapting, or data shows low acceptance rates.
