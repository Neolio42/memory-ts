PATTERN: When doing bulk content fixes across 10+ files, use parallel coding agents:
1. Read all affected files first (understand full scope)
2. Categorize changes by type (e.g., pricing fixes / breadcrumb fixes / hub page creation)
3. Launch 3 agents in parallel, each handling one category
4. Run build + prettier + tsc + lint after all agents finish
5. Fix prettier separately (npx prettier --write on failed files)

WHEN: Any bulk content edit across more than 3 files

WHY: Significantly faster than sequential edits. 3 agents doing 7 files each completes in ~same time as 1 file edited sequentially.

GOTCHA: Prettier often fails after agent edits — always run check + write pass at the end. Pre-existing lint warnings (unused vars in admin code) are not regressions from our changes.
