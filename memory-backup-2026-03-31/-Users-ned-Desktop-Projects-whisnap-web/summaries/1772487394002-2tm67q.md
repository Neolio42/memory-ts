Diagnosed a cloud sync system (Whisnap web) where the admin dashboard showed phantom fields due to camelCase vs snake_case mismatch between desktop app and server schema. The desktop app was sending camelCase fields while the server schema defined snake_case, and Zod's .passthrough() was silently storing all garbage. Session ended with a complete redesign plan: strict allowlist of 11 snake_case field paths, no passthrough, snippets and custom_vocabulary as atomic LWW fields, and a DB migration to clean up all camelCase duplicates and junk fields.
