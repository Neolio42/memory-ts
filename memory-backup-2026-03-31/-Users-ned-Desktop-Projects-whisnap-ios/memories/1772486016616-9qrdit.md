ARCHITECTURE:
PATTERN: Main app RelayService writes PCM audio chunks to App Group shared directory. KeyboardTranscriptionService reads chunks and streams to WebSocket.
COMPONENTS:
  - App Group: group.com.whisnap.app
  - Keychain sharing: G5C2K9X7XG.com.whisnap.shared
  - Relay keys: relayActive (Bool), relayExpiry (Double/timestamp), relayChunkCount (Int)
  - Chunks: chunk_000000.pcm, chunk_000001.pcm etc. in shared container
  - Build: xcodebuild -scheme Whisnap -configuration Debug build -destination 'generic/platform=iOS'
WHY: Keyboard extension runs in separate process — cannot communicate directly with main app
GOTCHA: UserDefaults MUST call .synchronize() before reading in keyboard extension, otherwise stale cached values are returned. This was the root cause of relay toggle not responding.
