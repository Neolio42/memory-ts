WHAT: NSTimer scheduled in .default run loop mode stops firing when UIScrollView is tracking (common mode), causing relay polling gaps.

WHERE: KeyboardViewController.startRelayPolling()

HOW:
```swift
// WRONG — pauses during scroll:
relayPollTimer = Timer.scheduledTimer(withTimeInterval: 2.0, repeats: true) { [weak self] _ in
    self?.pollForRelay()
}

// CORRECT — fires even during scroll:
relayPollTimer = Timer(timeInterval: 2.0, repeats: true) { [weak self] _ in
    self?.pollForRelay()
}
RunLoop.main.add(relayPollTimer!, forMode: .common)
```

WHY: `.default` run loop mode doesn't execute timers when the run loop is in `.tracking` mode. `.common` mode includes both `.default` and `.tracking`.

GOTCHA: Must hold a strong reference to the timer — `Timer(timeInterval:)` without `scheduledTimer` doesn't auto-schedule.
