TECHNICAL
WHAT: UserDefaults(suiteName: appGroupSuite) changes made in main app are not immediately visible to keyboard extension without explicit synchronize()
WHERE:
- Writer: RelayService.swift — writeChunk(), updateSharedMetadata(), stopSession()
- Reader: KeyboardTranscriptionService.swift — readNewChunks(), hasActiveRelay()
HOW:
// Writer side (RelayService)
sharedDefaults?.set(currentIndex, forKey: RelayKeys.relayChunkCount)
sharedDefaults?.synchronize()  // REQUIRED
// Reader side (KeyboardTranscriptionService)
sharedDefaults?.synchronize()  // Force fresh read
let count = sharedDefaults?.integer(forKey: KeyboardConstants.relayChunkCount)
WHY: iOS UserDefaults writes are eventually consistent for cross-process access. Without synchronize(), keyboard may see count=0 even after 10 chunks written.
GOTCHA: App Group suite name must match exactly: 'group.com.whisnap.app'
