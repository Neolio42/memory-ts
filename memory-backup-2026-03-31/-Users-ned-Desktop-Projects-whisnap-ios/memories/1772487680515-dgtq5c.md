DECISION: Added kSecAttrAccessGroup to all three keychain operations (set/get/delete) in App/Data/KeychainManager.swift

DETAILS:
- Access group constant: `G5C2K9X7XG.com.whisnap.shared` (team ID hardcoded)
- This allows WhisnapKeyboard extension to read auth tokens stored by the main app
- Required because keyboard extensions run in a separate process
- App Groups entitlement: `group.com.whisnap.app`
- Keychain Sharing entitlement: `$(AppIdentifierPrefix)com.whisnap.shared`

WARNING — SIDE EFFECT:
Adding kSecAttrAccessGroup to existing keychain items means all previously stored tokens are now inaccessible (they were stored without the access group key). Existing users WILL be signed out. Acceptable for pre-release.

FIX: Delete and reinstall the app, or implement a migration that reads the old item and re-saves with the access group.

REVISIT WHEN: Moving to production release — may need a one-time keychain migration
