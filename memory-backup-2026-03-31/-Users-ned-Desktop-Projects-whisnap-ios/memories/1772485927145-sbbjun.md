WHAT: Debug logging system added to KeyboardViewController with emoji prefixes for easy filtering
WHERE: WhisnapKeyboard/KeyboardViewController.swift throughout
HOW: Filter Xcode console by '🎹 [KB]' for keyboard lifecycle, '🎙️ [KB]' for recording, '🔗 [KB]' for deep links, '✅ [KB]' for success, '❌ [KB]' for errors
LOGGED EVENTS:
- viewDidLoad: keyboard loaded with needsInputModeSwitchKey
- viewWillAppear: auth state, relay state, globe needed
- refreshVoiceStrip: what state was set and why
- keyboardViewDidTapMic: what action was taken
- startRecording/stopRecording: with timestamps
- transitionTo: state machine transitions with reason
- openApp: URL attempted, responder chain result, extensionContext result
WHY: Previously zero logging, making keyboard extension debugging impossible
