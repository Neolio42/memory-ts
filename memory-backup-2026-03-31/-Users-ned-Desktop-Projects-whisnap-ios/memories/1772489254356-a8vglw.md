FACT: User calls out BS directly and uses profanity when frustrated ('what the fuck', 'pure bullshit', 'I call bs'). When bugs are dismissed as 'standard iOS behavior', they push back hard and are usually right.

CONTEXT: User had the gesture timeout dismissed as simulator noise. Turned out it was caused by the kSecAttrAccessGroup bug causing all keychain operations to fail, which was causing cascading failures across the app.

AFFECTS: Never dismiss runtime errors as 'simulator noise' without actually verifying. When user says something feels wrong, investigate first. Show the investigation ('let me actually look') rather than asserting.

PATTERN: User values: (1) comprehensive coverage — 'we only reviewed 3 files???' means go wide, (2) honest debugging — trace the actual cause, don't speculate, (3) action over explanation — fix it, then briefly explain what happened.
