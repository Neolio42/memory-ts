DEBUG
SYMPTOM: 'Socket is not connected' WebSocket errors, no transcripts generated
CAUSE: Auth message sent immediately after task.resume() before server sends 'connected' event — server ignores premature auth
FIX: Implement state machine waiting for server messages:
1. Call connect() / task.resume()
2. Wait for server message type='connected'
3. Send {type:'auth', token: jwt}
4. Wait for server message type='auth_success'
5. Send {type:'start_transcription', session_id: ...}
6. Wait for server message type='transcription_started'
7. Call beginStreaming() — flush existing chunks from index 0, then poll every 0.15s
