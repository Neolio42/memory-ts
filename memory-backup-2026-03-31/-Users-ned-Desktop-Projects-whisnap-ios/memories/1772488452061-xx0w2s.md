PATTERN: iOS Custom Keyboard Extension (KeyboardExtension target) added to existing voice/AI app

DESIGN:
- Full normal QWERTY keyboard layout (not mic-only)
- Mic button integrated into keyboard (e.g., bottom row or replace space bar area)
- On mic press: button transforms into animated recording waveform
- On speech end: transcribed text pasted into the host app's active text field via textDocumentProxy.insertText()
- Keyboard should feel familiar — standard key layout, autocorrect/suggestions preserved or mimicked

SESSION SHARING:
- Keyboard extension and main app share session/auth state via App Group + shared UserDefaults or Keychain
- 'Always Allow Full Access' entitlement required for network calls from keyboard

ONBOARDING:
- App needs a setup screen instructing user: Settings → General → Keyboard → Keyboards → Add New Keyboard
- Possibly auto-deep-link to Settings via UIApplication.open(URL(string: UIApplication.openSettingsURLString))

KEY API:
- textDocumentProxy.insertText(transcribedString) — pastes into active field from any app
- UIInputViewController — base class for keyboard extension

STATUS: Plan written, implementation not started
