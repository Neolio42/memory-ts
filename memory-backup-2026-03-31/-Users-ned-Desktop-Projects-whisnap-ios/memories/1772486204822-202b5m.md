SYMPTOM: SourceKit (Xcode IDE) shows red 'Cannot find X in scope' errors after edits
CAUSE: Cross-module references (keyboard extension ↔ shared code, main app ↔ shared code) cause SourceKit's indexing to report false errors
FIX: Ignore SourceKit errors. Always verify with actual build:
  xcodebuild -scheme Whisnap -configuration Debug build -destination 'generic/platform=iOS' -project /Users/ned/Desktop/Projects/whisnap-ios/Whisnap-IOS/Whisnap.xcodeproj
PREVENT: Never change code to satisfy SourceKit errors — run the actual build to determine if errors are real
NOTE: UIKit import errors in WhisnapKeyboard files are also false positives
