WHAT: All Whisnap keyboard metrics match native iOS keyboard within 0.3pt

FINAL VALUES:
- Key height: 45pt (fillEqually distributes correctly with 261pt frame)
- Horizontal gap (keySpacing): 6pt
- Vertical gap (rowSpacing): 11pt  
- Side margin (sideInset): 4pt → produces 8.7pt visual margin (matches native)
- Shift/Delete spacer: 2pt (was 4pt — caused keys to be 2pt too narrow)
- Shift↔Z total gap: 6+2+6 = 14pt ≈ native 13.7pt
- Background color: #E2E4E8
- Corner radius: 7.0pt
- Toolbar height: 44pt

WHY spacer=2pt: Stack spacing of 6pt between each subview, with a 2pt UIView spacer between shift/Z and delete/M: 6+2+6=14pt gap matching native's 13.7pt.
