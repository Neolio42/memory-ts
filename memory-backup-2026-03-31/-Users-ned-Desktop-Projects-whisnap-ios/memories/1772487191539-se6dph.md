TECHNICAL: How keyboard decides whether Relay is available.

KEYBOARD FLOW:
1. User taps mic button in keyboard
2. hasActiveRelay() is called:
   - Read relayActive (Bool) from shared UserDefaults (AppGroup)
   - Read relayExpiry (Date) from shared UserDefaults
   - Returns true if relayActive == true AND relayExpiry > Date()
3. If active → startRecording() via KeyboardTranscriptionService
4. If NOT active → openAppForRelay() → opens whisnap-ios://relay

WRITTEN BY RelayService (main app process):
- relayActive = true/false
- relayExpiry = Date (startTime + duration * 60)
- relayChunkCount = Int (incremented on each chunk write)

READ BY KeyboardViewController (keyboard process):
- uses UserDefaults(suiteName: AppGroup.suiteName)

CHUNK POLLING:
- KeyboardTranscriptionService polls at 200ms intervals
- Reads chunk_000001.pcm, chunk_000002.pcm ... up to current relayChunkCount
- Tracks lastReadChunk index to only read new chunks
- Sends raw bytes as base64 to WebSocket

COUNTDOWN: RelayView calculates from actual expiry timestamp (not decrement) to prevent drift
