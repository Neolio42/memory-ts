SHIPPED: Full RecordingOverlayView rewrite in WhisnapKeyboard/RecordingOverlayView.swift

KEY DESIGN:
- Background: UIVisualEffectView(.systemMaterial) — adapts light/dark
- Waveform: 7 bars, 6pt wide, cornerRadius 3, 3 overlapping sine waves at different frequencies, phase speed 0.06, barHeightConstraints cached for O(1) updates
- Transcript pill: cornerRadius 12, tertiarySystemBackground 90% opacity, shadow, 3 lines, italic 'Listening...' placeholder, micro-bounce on update
- Stop: 56pt red circle, stop.fill icon, red glow shadow
- Cancel: pill shape, systemGray5 bg, secondaryLabel text
- Processing: 3 bouncing blue dots, 0.15s staggered delays
- Done: green checkmark springs from 0.5 scale (damping 0.6), 'Text inserted', hold 1.2s
- Error: CAKeyframeAnimation shake (values [-8,8,-4,4,0]) + orange status
- Haptics: medium on start, light on stop/cancel, success on done, error notification on error
- New property: `var finalTranscript: String` — set before .done state
- stateGeneration counter guards stale animation completions
- Cross-hierarchy width constraint moved to after view added to hierarchy

SIGNIFICANCE: Previous UI was bare-bones (thin red bars, instant state swaps). New version is native-quality with proper state choreography.
