SYMPTOM: Console spammed with '🎤 [TAP] processAudioBuffer called - frameLength: 4800' etc at every audio buffer callback
CAUSE: Debug prints left in AudioCaptureService.processAudioBuffer() and CloudTranscriptionService.handleAudioBuffer() — these fire ~10x/second during recording
FIX: Removed ALL per-buffer prints from:
  - AudioCaptureService.processAudioBuffer() — removed 10+ prints, kept only silence detection
  - CloudTranscriptionService.handleAudioBuffer() — removed 6+ prints
  - AudioQueueActor.enqueue() — removed queue status prints (kept overflow warning)
PREVENT: Never add per-buffer prints to audio callback paths. Use counters or occasional sampling if needed for debugging.
