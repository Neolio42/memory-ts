SYMPTOM: 401 API call on first startup even when not logged in — `📡 API Response: 401` in logs

CAUSE: iOS Keychain is NOT cleared when app is deleted/reinstalled. UserDefaults IS cleared. Stale refresh tokens from previous install trigger AuthService.checkAuthenticationStatus() → refresh attempt → 401.

FIX: In AuthService.init(), call clearKeychainOnFreshInstall() which checks UserDefaults `hasLaunchedBefore` flag. On first launch after install (flag absent), clear all keychain tokens. Set flag immediately after.

PREVENT: Always use this pattern for any iOS app that stores tokens in keychain. Standard iOS best practice.

WHERE: AuthService.swift — clearKeychainOnFreshInstall() called from init()

GOTCHA: UserDefaults.standard NOT UserDefaults(suiteName:) — app group UserDefaults persists differently. Use standard for this flag.
