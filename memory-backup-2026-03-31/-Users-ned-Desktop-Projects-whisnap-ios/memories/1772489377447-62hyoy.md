PATTERN: SettingsView must observe both its own ViewModel AND AuthService for correct reactive behavior.

KEY CHANGES:
1. `@StateObject private var viewModel = SettingsViewModel()` — NOT @State (reference type needs @StateObject)
2. `@ObservedObject private var authService = AuthService.shared` — direct observation for live auth state
3. Sign-in section: `if !authService.isAuthenticated { Button('Sign In') { showingSignIn = true } }` — was missing entirely!
4. Account section reads from `authService.userEmail` directly — not stale ViewModel copy
5. Sheet auto-dismiss: `.onChange(of: authService.isAuthenticated) { if $1 { showingSignIn = false } }`

Do NOT read auth state from SettingsViewModel computed properties — they don't forward objectWillChange.

WHERE: SettingsView.swift

GOTCHA: Alert must use `@State var showingErrorAlert` with `.onChange(of: viewModel.errorMessage)` to set it — cannot use `.constant(viewModel.errorMessage != nil)` which creates a non-dismissable alert.
