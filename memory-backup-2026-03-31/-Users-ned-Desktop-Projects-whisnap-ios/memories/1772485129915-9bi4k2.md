DEBUG
SYMPTOM: Deep links are unreliable / not working in iOS keyboard extension app
CAUSE: Using deprecated `openURL:` selector (UIApplication) which iOS warns about in console and may silently fail on modern iOS versions
FIX: Replace all `openURL:` calls with `open:options:completionHandler:` - the modern UIApplication API
PREVENT: Always use open:options:completionHandler: for URL opening from keyboard extensions. Also handle cold-launch race condition: notifications sent before keyboard finishes init are lost - queue them and replay after viewDidLoad completes
