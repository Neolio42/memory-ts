DEBUG
SYMPTOM: Fatal error: Received an output without requesting demand (Combine/Publisher+AsyncSequence.swift:112)
CAUSE: The Publisher.values async sequence adapter crashes when the publisher fires before demand is established. This is a known Combine/Swift Concurrency bridge bug.
FIX: Replace `for await _ in publisher.values` with `.onReceive(publisher) { _ in ... }` — the idiomatic SwiftUI approach that handles backpressure correctly.
CODE:
  // WRONG - crashes:
  .task { for await _ in vm.objectWillChange.values { toggle() } }
  // CORRECT:
  .onReceive(vm.objectWillChange) { _ in toggle() }
PREVENT: Never use Publisher.values in a SwiftUI view's .task modifier for hot publishers like objectWillChange. Use .onReceive for all Combine-to-SwiftUI bridging.
