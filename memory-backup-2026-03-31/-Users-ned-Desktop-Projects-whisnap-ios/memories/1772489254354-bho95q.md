PATTERN: Single @MainActor AuthService singleton as the only source of auth truth.

COMPONENTS:
- AuthService.swift: @MainActor, @Published isAuthenticated/userEmail/userPlan/authError, Combine cancellables for foreground refresh + WebSocket failures
- KeychainManager.swift: Thread-safe (Security framework), hasCredentials computed property, no queue wrapper needed
- APIClient.swift: getValidToken() with TokenRefreshActor, getUserInfo/logout use getValidToken()
- ContentView.swift: Observes authError, shows alert with proper Binding (not .constant)
- Whisnap_IOSApp.swift: handleMagicLinkToken delegates to AuthService.handleMagicLink(token:)

KEY DECISIONS:
- signOut() is non-throwing — always clears local state even if server unreachable
- wasAuthenticatedThisSession prevents auth alerts on cold launch with stale tokens
- isRefreshing guard prevents concurrent refresh attempts
- .dropFirst() on didBecomeActiveNotification — launch handled by checkAuthenticationStatus()
- handleRefreshFailure() always clears keychain so retry loop can't form
