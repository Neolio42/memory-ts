SYMPTOM: App crash 'Unable to activate constraint with anchors because they have no common ancestor. Does the constraint or its anchors reference items in different view hierarchies?'
CAUSE: Cross-row width constraints (e.g. row2 button.width == masterKey.width where masterKey is in row1) were activated before both rows were added to the container stack view. No common ancestor existed at constraint activation time.
FIX: Collect all cross-row constraints into a `deferredConstraints` array, then activate all at once via NSLayoutConstraint.activate() AFTER all rows are added to the container.
```swift
var deferredConstraints: [NSLayoutConstraint] = []
// ... build rows, append cross-row constraints to deferredConstraints ...
// After all rows added:
NSLayoutConstraint.activate(deferredConstraints)
```
PREVENT: Any constraint that references a view in a DIFFERENT stack view must be deferred until both views share a common ancestor in the view hierarchy.
