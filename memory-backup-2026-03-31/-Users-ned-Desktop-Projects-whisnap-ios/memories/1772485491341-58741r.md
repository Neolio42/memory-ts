SYMPTOM: 'nw_write_request_report Send failed with error Socket is not connected' + no transcript on first keyboard recording
CAUSE: Old code called task.resume() then immediately sent JSON auth message — socket not established yet. Then sent start_transcription after 0.3s delay — still may not be ready.
FIX: Proper state machine in receiveMessage loop:
  1. Wait for 'connected' message from server
  2. THEN send auth JSON
  3. Wait for 'auth_success'
  4. THEN send 'start_transcription'
  5. Wait for 'transcription_started'
  6. THEN begin polling audio chunks
PREVENT: Never send messages to a WebSocket immediately after resume(). Always wait for server confirmation at each step.
