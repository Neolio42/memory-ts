WHAT: startRecording() checks relayService.isActive to choose audio source
WHERE: CloudTranscriptionService.swift startRecording(), stopRecording(), reset()
HOW:
  if relayService.isActive:
    usingRelay = true → relayService.onAudioChunk = { handleAudioBuffer }
  else:
    usingRelay = false → audioCaptureService.startRecording() → audioCaptureService.onAudioBuffer = { handleAudioBuffer }
  stopRecording:
    if usingRelay: relayService.onAudioChunk = nil  (relay keeps running)
    else: audioCaptureService.onAudioBuffer = nil + audioCaptureService.stopRecording()
  reset(): always nils both callbacks and sets usingRelay = false
GOTCHA: setupCallbacks() must NOT register relayService.onAudioChunk at init — only during startRecording()
GOTCHA: setupRelayMonitoring() subscribes to relayService.$isActive — if relay dies mid-recording and usingRelay==true, auto-stops recording with error message
