SYMPTOM: AVAudioEngine.start() throws error 2003329396 ('what') in keyboard extension: 'AUIOClient_StartIO failed'
CAUSE: Host app (Notes, Messages, etc.) holds an active audio session. Keyboard extension's audio session tries to exclusively claim hardware, causing conflict. Using .record or .playAndRecord without .mixWithOthers both fail.
FIX: AVAudioSession.setCategory(.playAndRecord, mode: .voiceChat, options: [.mixWithOthers, .allowBluetooth]) + retry: on engine.start() failure, setActive(false), sleep 300ms, setActive(true), retry engine.start() once
PREVENT: Always use .mixWithOthers for keyboard extensions — they ALWAYS run alongside host apps that may have active audio sessions. .voiceChat mode optimizes audio route for voice input. Set preferredSampleRate(16000) and preferredIOBufferDuration(0.02) before start.
