DEBUG
SYMPTOM: Keyboard startup not working as intended; notifications/events lost on cold launch
CAUSE: Deferred initialization set to 1.5s delay means any notifications arriving before that window are lost. Globe key state not set until after layout pass causes visible jump.
FIX:
1. Move globe key setup to viewDidLoad (no delay) to prevent layout jump
2. Reduce deferred init timer from 1.5s to 0.3s to close the lost-notification window
3. Refresh voice strip after polling starts
PREVENT: Queue notifications received before init completes and replay them once keyboard is ready
