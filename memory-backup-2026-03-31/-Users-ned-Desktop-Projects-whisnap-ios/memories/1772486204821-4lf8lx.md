SYMPTOM: openURL not working from keyboard extension to open main app
CAUSE: Keyboard extension can't call UIApplication.shared directly (compile-time restriction). Walking responder chain looking for openURL: selector is unreliable in iOS 16+.
FIX: Get UIApplication.shared via ObjC runtime:
  let selectorShared = NSSelectorFromString('sharedApplication')
  guard let appClass = NSClassFromString('UIApplication'),
        let app = appClass.perform(selectorShared)?.takeUnretainedValue() as? UIApplication
  else { return }
  let selectorOpen = NSSelectorFromString('openURL:')
  app.perform(selectorOpen, with: url)
URL SCHEME: whisnap-ios:// registered in main app Info.plist
URL for relay: whisnap-ios://relay
URL for settings: whisnap-ios://settings
PREVENT: Never use responder chain walk for openURL in keyboard extensions
