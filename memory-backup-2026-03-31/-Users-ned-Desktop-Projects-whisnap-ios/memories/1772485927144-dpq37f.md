DEBUG
SYMPTOM: User taps relay toggle, nothing visible happens. Toggle eventually switches on but no audio captured.
CAUSE (two-part):
1. Toggle binding was fire-and-forget Task{} — visual toggle state only changed after async startSession() completed (race condition made it look stuck)
2. AudioCaptureService.startRecording() can take 3-6 seconds if not pre-warmed (setupAudioSessionSync() is blocking inside async)
FIX APPLIED:
- Added @State isRelayStarting = false in SettingsView
- ProgressView spinner shown next to toggle while starting
- Toggle disabled during startup (transcriptionService.status.isRecording || isRelayStarting)
- Binding: set isRelayStarting=true before Task, false in defer-like pattern after
FIX STILL NEEDED:
- AudioCaptureService prewarm not called before relay starts
- prepareForRecording() should be called when user opens Settings
