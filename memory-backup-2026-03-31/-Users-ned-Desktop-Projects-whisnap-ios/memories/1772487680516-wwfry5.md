MILESTONE: Complete audit + fix cycle on keyboard extension implementation.

CRITICAL FIXES APPLIED:
1. Force unwrap `self!` in delete timer → guard let pattern (KeyboardView.swift:503)
2. CADisplayLink retain cycle → DisplayLinkProxy weak proxy class (RecordingOverlayView.swift:22-37)
3. Unbounded audio chunk tasks → inFlightChunks counter, drops when >5 (KeyboardTranscriptionService.swift:130-140)
4. audioLevel data race (audio thread vs main) → os_unfair_lock protection (KeyboardAudioCaptureService.swift)
5. No audio interruption handling → observers for interruptionNotification + routeChangeNotification

HIGH FIXES:
6. 2s Task.sleep blocking MainActor → 100ms polling loop with early return
7. IsASCIICapable=false → true in Info.plist
8. Double-tap shift UIGestureRecognizer conflict → CACurrentMediaTime() time-based detection
9. Missing deinit → added timer invalidation + service cancellation
10. WebSocket session not finalized on audio failure → finalize() in error path

MEDIUM/LOW FIXES:
- Full layout rebuild on shift → updateLetterCase() updates titles in-place
- Added accessibilityLabel + .keyboardKey trait to all buttons
- State machine transition validation in KeyboardState.canTransition(to:)
- Session UUID guards on all callbacks (stale transcript prevention)
- UIImpactFeedbackGenerator on all key taps
- Cached waveform geometry (cachedTotalWidth/cachedStartX) in layoutSubviews
- shouldRasterize + rasterizationScale on all button shadow layers
- KeyboardConstants.appGroupSuite extracted from magic strings
