BUG: `grouped.sorted { $0.key > $1.key }` sorts date group label strings lexicographically. 'Yesterday' > 'Today' alphabetically = wrong display order.

FIX: Sort by the most recent timestamp in each group:
```swift
return grouped.sorted { lhs, rhs in
    let lhsDate = lhs.value.first?.timestamp ?? .distantPast
    let rhsDate = rhs.value.first?.timestamp ?? .distantPast
    return lhsDate > rhsDate
}
```
Items are pre-sorted descending from SwiftData query, so `.first?.timestamp` gives the most recent date per group.

WHERE: HistoryViewModel.swift line ~121

GOTCHA: This requires items within each group to already be sorted descending by timestamp (they are, from the SwiftData @Query descriptor).
