WHAT: The middle letter row (ASDF..JKL) needs to be indented ~18pt on each side relative to the Q-P row to match native keyboard centering.
HOW: Use `layoutMargins` + `isLayoutMarginsRelativeArrangement` directly on the row UIStackView:
```swift
let row2 = UIStackView()
row2.axis = .horizontal
row2.spacing = keySpacing
row2.distribution = .fill
row2.isLayoutMarginsRelativeArrangement = true
// Set via leftSpacer/rightSpacer with equal widths for flexible centering
```
Current implementation uses transparent spacer views (leftSpacer/rightSpacer with equal width constraint) so that row 2 keys automatically center based on master key width.
REJECTED: wrapWithPadding() wrapper UIView — this approach was deleted because `.fillEqually` distribution inside a wrapper prevents the master key width constraint approach from working.
GOTCHA: All ASDF keys must have `widthAnchor.constraint(equalTo: masterKey.widthAnchor)` activated AFTER all rows added to container (deferred constraints).
