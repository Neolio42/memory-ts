SYMPTOM: No partial transcripts shown in keyboard overlay during recording
CAUSE: Server sends: { 'type': 'partial_transcript', 'data': { 'text': 'hello', 'sessionId': 'abc' } }
Keyboard was reading json['text'] at top level — always nil. Every server response silently dropped.
FIX: Added value(forKey:in:) helper that checks both top-level and nested 'data' object:
  func value(forKey key: String, in json: [String: Any]) -> Any? {
      return json[key] ?? (json['data'] as? [String: Any])?[key]
  }
Apply to: partial_transcript, transcript, transcription_complete, session_stopped, error messages
NOTE: Main app uses Codable decoder which handles both formats automatically
PREVENT: When parsing WebSocket server messages in keyboard, always check both json[key] and json['data'][key]
