PATTERN: To debug keyboard extension with Xcode attached:
1. Edit Scheme → select WhisnapKeyboard scheme (not main app)
2. Set Executable to 'Ask on Launch'
3. Hit Cmd+R → picks Messages (or any app) as host
4. Debugger attaches to extension process
5. print() output appears in Xcode console, breakpoints work, crash stacks visible

IMPORTANT: First install main app (Whisnap scheme) so keyboard appears in Settings > General > Keyboard > Add New Keyboard.

SIMULATOR WORKFLOW:
- Builds 3-5x faster than device
- iPhone 17 Pro simulator on iOS 26 available
- All console spam (Messages app errors, iCloud errors, CHHapticPattern errors) is simulator noise — IGNORE IT
- Keyboard logs appear as 🎹 [KB] prefix

GOTCHA: 'WARNING: Did not receive handshake message' and 'Couldn't communicate with a helper application' are normal simulator noise, not keyboard errors.
