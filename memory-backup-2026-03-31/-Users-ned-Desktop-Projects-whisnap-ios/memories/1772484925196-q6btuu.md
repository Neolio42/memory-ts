SYMPTOM: Console warning: '-[UIInputViewController needsInputModeSwitchKey] was called before a connection was established to the host application. This will produce an inaccurate result.'

CAUSE: Host connection to the containing app isn't established until after viewDidAppear, and on spurious extension launches it may still not be ready.

FIX: Move needsInputModeSwitchKey read into the 0.3s deferred block in viewDidAppear:
```swift
override func viewDidAppear(_ animated: Bool) {
    super.viewDidAppear(animated)
    DispatchQueue.main.asyncAfter(deadline: .now() + 0.3) { [weak self] in
        guard let self else { return }
        self.keyboardView.showGlobe = self.needsInputModeSwitchKey  // safe here
        self.checkPendingTranscription()
        self.startRelayPolling()
        self.reportKeyboardStatus()
    }
}
```

Since showGlobe now toggles isHidden instead of rebuilding layout, there's no visible jump.

PREVENT: Never call needsInputModeSwitchKey in viewDidLoad or synchronously in viewDidAppear.
