SYMPTOM: App hangs/transcription never completes when server doesn't respond within timeout window

CAUSE: `withThrowingTaskGroup` drains all child tasks before its closure can return/throw. Task 1 is suspended in `withCheckedThrowingContinuation` waiting for its continuation to be resumed. The timeout code that should resume it was in the OUTER catch block — which can't run until the group returns. Circular dependency = deadlock.

FIX: Move continuation cleanup INSIDE the task group closure. When timeout task completes first, it explicitly cancels/resumes the continuation task BEFORE the group tries to drain its children.

WHERE: CloudTranscriptionService.swift lines 483-514 (withThrowingTaskGroup), lines 847-857 (callback handler)

GOTCHA: CheckedContinuation must be resumed EXACTLY ONCE. Both the timeout path and the callback path must guard with nil-check-and-clear (atomic swap pattern) before resuming.
