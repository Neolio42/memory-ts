WHAT: Disable Qwen 3.5 9B thinking mode via assistant prefill in LM Studio API
HOW: Add assistant message before model response:
  {"role": "assistant", "content": "<think>\n</think>\n"}
WHY: Without this, Qwen outputs lengthy reasoning chains before JSON, making parsing unreliable and slowing throughput from 170/hr to 1000+/hr
WHEN TO USE: Any structured output task (JSON extraction, classification, categorization) where thinking overhead hurts more than helps
LM STUDIO API: OpenAI-compatible at localhost:1234, Qwen 3.5 9B GGUF Q4_K_M
TEMPERATURE: 0.1 for consistent structured outputs (not 1.0 - would make responses random/inconsistent)
