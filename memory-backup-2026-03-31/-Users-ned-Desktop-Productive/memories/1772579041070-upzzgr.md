WHAT: memory serve runs as a persistent launchd agent, not a manual process.
WHERE: ~/Library/LaunchAgents/com.rlabs.memory.plist; logs at ~/.local/share/memory/server.log
HOW: Starts automatically on login (RunAtLoad: true), restarts on crash (KeepAlive: true). Port 8765. No need to manually run `memory serve`.
WHY: Required for hooks to work reliably across all Claude Code sessions without manual intervention.
GOTCHA: If server seems broken:
- Check: `launchctl list | grep memory`
- Logs: `tail ~/.local/share/memory/server.log`
- Reload: `launchctl load ~/Library/LaunchAgents/com.rlabs.memory.plist`
