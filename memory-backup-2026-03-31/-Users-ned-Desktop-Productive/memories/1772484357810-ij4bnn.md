SYMPTOM: SessionStart and UserPromptSubmit hooks showing error in Claude Code UI even when server is running fine

CAUSE: Claude Code's hook runner doesn't source ~/.zshrc so `bun` is not in its PATH. The hooks use `bun` as interpreter but the binary can't be found.

FIX: In ~/.claude/settings.json, replace all `bun` references with full path:
  "bun /path/to/hook.ts" → "/Users/ned/.bun/bin/bun /path/to/hook.ts"

PREVENT: Always use absolute paths for interpreters in Claude Code hooks. Hooks run in a minimal environment without shell profile. Affects any tool installed in user space (bun, deno, node via nvm, etc.)
