WHAT: memory serve runs as a launchd agent, not a manual process.
WHERE: ~/Library/LaunchAgents/com.rlabs.memory.plist; logs at ~/.local/share/memory/server.log
HOW: Starts automatically on login (RunAtLoad: true), restarts on crash (KeepAlive: true). Port 8765. No need to manually run `memory serve`.
WHY: Needed for hooks to work reliably across all Claude Code sessions without manual intervention.
GOTCHA: If server seems broken, check `launchctl list | grep memory` and `tail ~/.local/share/memory/server.log`. Use `launchctl load ~/Library/LaunchAgents/com.rlabs.memory.plist` to reload if needed.
