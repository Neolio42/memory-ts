SYMPTOM: `memory ingest` commands fail with exit code 1 when run from inside a Claude Code session
CAUSE: memory ingest spawns new Claude Code processes under the hood. Claude Code detects the CLAUDECODE env var and blocks nested launches.
FIX: Always run `memory ingest` commands from a separate terminal, NOT from within Claude Code
COMMAND FORMAT: `memory ingest --session <id>` (NOT --session-id)
NESTED WORKAROUND: Don't try `unset CLAUDECODE` - user rejected this approach
PREVENT: When helping Ned with ingestion, always tell him to open a new terminal tab
