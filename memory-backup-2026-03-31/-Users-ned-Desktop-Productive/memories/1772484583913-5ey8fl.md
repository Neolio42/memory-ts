WHAT: Copy contents of a remote file to local macOS clipboard via SSH

HOW:
```bash
ssh agent "cat ~/.openclaw/workspace/HOW-YOU-WORK.md" | pbcopy
```

WHY: pbcopy is macOS-only. Running it on the remote machine won't work. Pipe SSH stdout into local pbcopy instead.

GOTCHA: Works for any file type. For JSON/MD files just swap the path.
