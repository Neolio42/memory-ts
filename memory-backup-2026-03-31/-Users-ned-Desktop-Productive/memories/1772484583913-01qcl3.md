SYMPTOM: 'Error: Running Homebrew as root is extremely dangerous and no longer supported'

CAUSE: OpenClaw runs as root. Homebrew refuses root execution.

FIX:
1. Create non-root user: useradd -m -s /bin/bash openclaw
2. Install homebrew as that user: su - openclaw -c '/bin/bash -c ...(install script)'
3. Create wrapper at /usr/local/bin/brew:
   ```bash
   #!/bin/bash
   exec su - openclaw -c "/home/linuxbrew/.linuxbrew/bin/brew \"$@\""
   ```
4. chmod +x /usr/local/bin/brew

PREVENT: For any VPS-based tool setup that uses brew, always check if the process runs as root first.

NOTE: This also affects any skill that uses brew under the hood - they'll use the wrapper automatically.
