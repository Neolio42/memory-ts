WHAT: memory serve runs as a launchd agent, not a manual process.
WHERE: ~/Library/LaunchAgents/com.rlabs.memory.plist
HOW: Starts automatically on login (RunAtLoad: true), restarts on crash (KeepAlive: true). Logs at ~/.local/share/memory/server.log. No need to manually run `memory serve`.
WHY: Needed for hooks to work reliably across all Claude Code sessions without manual intervention.
GOTCHA: If server seems broken, check `launchctl list | grep memory` and `tail ~/.local/share/memory/server.log`
