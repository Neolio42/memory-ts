WHAT: @rlabs-inc/memory memory persistence system for Claude Code sessions
WHERE: Installed globally via `bun install -g @rlabs-inc/memory`; hooks at ~/.claude/hooks/; launchd plist at ~/Library/LaunchAgents/com.rlabs.memory.plist
HOW: Server runs automatically on login via launchd (KeepAlive+RunAtLoad). Hooks auto-inject session primers and surface relevant memories per message.
GOTCHA: Claude Code doesn't source .zshrc so bare `bun` fails in hooks. All hook commands must use full path: /Users/ned/.bun/bin/bun
GOTCHA 2: memory ingest CANNOT run from inside Claude Code session (nested session detection blocks it). Must run from a separate terminal.
GOTCHA 3: Correct model ID is `claude-sonnet-4-6` (no date suffix). `claude-sonnet-4-6-20250514` does NOT work.
