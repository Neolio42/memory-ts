SYMPTOM: `memory ingest` fails with exit code 1 from inside Claude Code session

CAUSE: `memory ingest` uses the Claude Agent SDK / `claude --resume` to curate each historical session. Claude Code blocks nested `claude` invocations - CLAUDECODE env var is set and the subprocess detects it.

FIX: Run `memory ingest --all` from a separate terminal (not inside any Claude Code session)

PREVENT: All memory curation commands that spawn Claude (ingest, manual curation) must run from outside Claude Code. Automatic end-of-session curation works because it runs after the session context is released.
