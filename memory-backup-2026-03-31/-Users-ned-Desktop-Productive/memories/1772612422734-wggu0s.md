PATTERN: Correct memory management sequence for batches of 5+ new memories:
  1. Glob all existing project + global memories
  2. Read primer and grep for domain/tag overlaps
  3. Read all action_required memories first (pending blockers may be resolved or related)
  4. Read new memories and identify relationship candidates
  5. Fix factual errors discovered via cross-reading BEFORE adding relationship links
  6. Add bidirectional related_to links in parallel batches
  7. Update primer last (informed by everything read above)
WHEN: Any curation session with 5+ new memories, especially when new memories touch personal/identity content
WHY: Factual errors in older memories get caught when cross-referencing new content (e.g., 'Dec 2024' in xc61el caught by comparing against new memory 4pqyz9 which stated 'Dec 2025'). Relationship map only makes sense after errors are fixed.
GOTCHA: Edit tool requires reading a file before editing it in the same session. Pre-read all files you intend to edit. Cannot batch edit without intervening reads — re-read immediately before each edit if needed.
