WHAT: @rlabs-inc/memory is the persistent memory layer for Claude Code with semantic retrieval, automatic session curation, and global/project memory scoping.
WHERE: Global install via `bun install -g @rlabs-inc/memory`; hooks in ~/.claude/settings.json; storage at ~/.local/share/memory/
HOW: Hooks fire automatically on SessionStart (primer injection), UserPromptSubmit (semantic retrieval), PreCompact/SessionEnd (curation).
WHY: Replaced stale static MD files reflecting December 2025 state — actively misleading context.
GOTCHA 1: Claude Code does not source ~/.zshrc so bare `bun` fails in hooks. Must use full path: /Users/ned/.bun/bin/bun in all hook commands in settings.json.
GOTCHA 2: `memory ingest` CANNOT run from inside a Claude Code session — nested session detection blocks it. Always run from a separate terminal.
GOTCHA 3: launchd service runs at port 8765. If hooks fail, check `launchctl list | grep memory` and `tail ~/.local/share/memory/server.log`.
