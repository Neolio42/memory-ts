WHAT: LM Studio serves Qwen 3.5 9B (Q4_K_M GGUF) at localhost:1234 with OpenAI-compatible API (/v1/chat/completions).
HOW: Disable thinking mode via assistant prefill for clean JSON:
```python
messages = [
  {"role": "system", "content": system_prompt},
  {"role": "user", "content": content},
  {"role": "assistant", "content": "<think>\n</think>\n"}  # Skips thinking
]
```
PARAMS: temperature=0.1 (deterministic), max_tokens=200. One item per request - Qwen gets confused with batches.
IMPACT: 170/hr with thinking → 1041/hr without. Same quality output.
GOTCHA: Cannot disable thinking via API params - prefill is the only way through OpenAI-compat endpoint.
