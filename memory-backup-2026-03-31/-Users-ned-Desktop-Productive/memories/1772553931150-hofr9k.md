WHAT: LM Studio serves local models at localhost:1234 with OpenAI-compatible API (/v1/chat/completions). Qwen 3.5 9B (Q4_K_M GGUF) installed.
HOW: To disable thinking mode and get clean JSON output, add assistant prefill message:
```python
messages = [
  {"role": "system", "content": system_prompt},
  {"role": "user", "content": content},
  {"role": "assistant", "content": "<think>\n</think>\n"}  # Disables thinking
]
```
WHY: With thinking enabled, model outputs reasoning before JSON, making extraction unreliable. Disabling = clean JSON, 5x faster (170/hr → 1041/hr).
GOTCHA: Temperature 0.1 for consistent categorization. Never batch multiple items per request - Qwen gets confused. One at a time. Max tokens 200 is sufficient for JSON responses.
