WHAT: LM Studio serves local models at localhost:1234 with OpenAI-compatible API (/v1/chat/completions). Qwen 3.5 9B (Q4_K_M) is installed.
HOW: To disable thinking mode (which makes JSON extraction unreliable), add assistant prefill:
```python
messages = [
  {"role": "system", "content": "..."},
  {"role": "user", "content": transcription},
  {"role": "assistant", "content": "<think>\n</think>\n"}  # Disables thinking
]
```
WHY: With thinking enabled, model outputs reasoning before JSON, making extraction brittle. Disabling it = clean JSON output, 5x faster (170/hr → 1041/hr).
GOTCHA: Temperature 0.1 for consistent categorization. Never batch multiple recordings per request - Qwen gets confused. One at a time.
