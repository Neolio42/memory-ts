INSIGHT: The agent (Atlas) was breaking the architecture by putting wrong content in wrong files (hardcoding specific scenarios in HEARTBEAT.md). The fix: give the agent a plain-English manual explaining what each file is for.

SOLUTION: ~/.openclaw/workspace/HOW-YOU-WORK.md explains:
- SOUL.md = personality, never for schedules
- HEARTBEAT.md = dumb trigger, keep under 20 lines, generic only
- Cron = time-specific tasks
- MEMORY files = what happened, not instructions
- HOW-YOU-WORK.md = this file, read before editing anything

SOUL.md was also updated with: 'Before editing any workspace file, read HOW-YOU-WORK.md first'

WHY THIS MATTERS: Same problem applies to Claude itself - without clear architecture docs, any AI will confidently put things in the wrong layer. The meta-lesson: when building agents, give them documentation about their OWN structure.

PATTERN: This is a general principle for any agent setup - self-documentation prevents architectural drift.
