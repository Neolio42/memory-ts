PATTERN: Memory curation management procedure - how to process a batch of new memories from the curator.
WHEN: Each curation pass when new memories arrive for processing.
STEPS:
1. List all memory files (Glob), read personal primer in parallel
2. Grep existing memories for same domain/context_type to find supersession candidates
3. For each new unresolved/state/debug memory: trace the chain (follow superseded_by links to find current head)
4. Supersede current head: add superseded_by field pointing to new memory, set action_required: false
5. Update new memory: add supersedes field, related_to links to chain members
6. Cross-link new memories to each other where topically related
7. Scan for stale action_required: true on ALL superseded memories and clear them
8. For personal memories: update primer if new facts warrant it
GOTCHA: Memories can have 'action_required: true' in body text (documentation examples) that grep will falsely match - always read the file to verify the metadata field, not just the body.
