WHAT: Correct model ID format for Claude APIs as of March 2026.
LATEST MODELS (no date suffix):
- claude-sonnet-4-6
- claude-opus-4-6
OLDER MODELS (still need date suffix):
- claude-haiku-4-5-20251001
- claude-sonnet-4-5-20250929
HOW TO VERIFY: `claude --model` to see current available list.
WHY: Pattern changed between generations — older models need YYYYMMDD suffix, latest generation models do NOT.
GOTCHA: claude-sonnet-4-6-20250514 is WRONG and will fail. The absence of date suffix is intentional for latest models, not an error.
