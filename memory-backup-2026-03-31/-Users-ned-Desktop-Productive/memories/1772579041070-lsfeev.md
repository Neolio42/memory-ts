WHAT: LM Studio serves local models at localhost:1234 with OpenAI-compatible API (/v1/chat/completions). Qwen 3.5 9B (Q4_K_M GGUF) installed.
HOW TO DISABLE THINKING MODE for clean JSON output:
```python
messages = [
  {"role": "system", "content": system_prompt},
  {"role": "user", "content": content},
  {"role": "assistant", "content": "<think>\n</think>\n"}  # Disables thinking
]
```
WHY: With thinking enabled, model outputs reasoning before JSON — makes extraction unreliable and slow (170/hr → 1041/hr with thinking disabled).
GOTCHA: Temperature 0.1 for consistent categorization. Never batch multiple items per request — Qwen gets confused. One at a time. Max tokens 200 sufficient for JSON responses.
