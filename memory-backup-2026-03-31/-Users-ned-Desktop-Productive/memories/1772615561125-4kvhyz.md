PATTERN: How to manage memory supersession and cross-linking in @rlabs-inc/memory system.
WHEN: Any session producing memories that update/refine earlier memories on same topic.
PROCESS:
1. Glob both project and global memory directories to find all files
2. Read candidates — identify supersession pairs by semantic content match (same topic, newer session wins)
3. Mark older memory: set status='superseded', add superseded_by='<new-id>'
4. Mark newer memory: add supersedes='<old-id>', add related_to links to related memories
5. Update anchor memories with links to new batch
6. Validate primer — update only if personal content adds genuinely new information
GOTCHA: Edit tool requires file to be read in the same message before editing. Process one file at a time: Read → Edit.
GOTCHA: When multiple batch files share the same topic cluster, read all before deciding supersession pairs to avoid circular or missing links.
