PATTERN: Every marketing animation follows 3-act structure

1. HOOK (2 seconds, full-screen):
   - Bold centered text on dark background
   - Key word(s) highlighted in #FF8C42 orange
   - Examples: 'Talk to your team.' / 'Still typing? Speak instead.' / 'Why type when you can talk?'

2. DEMO:
   - Focused app mock (just the compose bar, not full Slack client; just compose popup for Gmail)
   - Mouse cursor appears → moves to text field → clicks → disappears quickly (0.4s move, 0.1s fade)
   - FN key indicator appears → pulses with orange highlight
   - Whisnap pill activates: idle → recording (orange bars) → transcribing (bouncing white) → idle
   - Text PASTES AS A BLOCK (opacity 0→1) - never character by character

3. CTA ENDING:
   - Black screen
   - Whisnap logo + 'Whisnap' title
   - 'Free download for macOS'
   - 'whisnap.com' in orange

CANCEL: Mouse should disappear within 100ms of click - user said 'mouse sticks around' when it lingers
