PERSONAL:
FACT: User gives extremely direct, expletive-heavy feedback when slides miss the mark — multiple failed iterations create real frustration

CONTEXT: Building a startup pitch deck where every slide needs to tell a clear story. User has strong intuitions about visual design and narrative but sometimes needs to talk it out.

BEHAVIOR PATTERN:
- User said explicitly: 'why the fuck if you don't understand why don't you ask?'
- When slide logic is unclear, ASK before building
- When asked to 'stop making it, let's talk' — that means brainstorm first, code after
- User responds well to options presented as ASCII diagrams or bullet points
- Approvals are usually short: 'Yea this hits harder' / 'Yeah this looks pretty good'

SLIDE PREFERENCES:
- Punchy over detailed — less text is almost always better
- Strong visual hierarchy — one clear idea per slide
- Progressive reveal creates narrative tension (like free wedge cards 7-10)
- Parallel structure creates instant clarity ('Your X. Their Y.')
- 'The wow' should be obvious without reading — visual impact first

AFFECTS: Always validate the narrative/approach verbally before building multiple slides. One question upfront saves 6 failed iterations.
