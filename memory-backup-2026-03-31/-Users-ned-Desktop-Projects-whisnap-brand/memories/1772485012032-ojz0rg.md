ARCHITECTURE:
 PATTERN: Slides 7-10 (free wedge) each use a 4-card-slot layout. Slide 7 = 1 active + 3 dashed empty. Slide 8 = 2 active + 2 dashed empty. Slide 9 = 3 active + 1 dashed empty. Slide 10 = all 4 active, no empty slots.
 COMPONENTS: Each slide has same outer container with 4 children. Active cards = solid border + colored text. Empty placeholder slots = dashed #333 border, height matches active cards, no text.
 WHY: Maintains visual continuity across slides — audience sees what's coming and feels buildup
 REJECTED: Single big card for first slide (slide 7 originally had this) — caused jarring layout jump when advancing to slide 8
 GOTCHA: If subagents build slides independently, they'll make inconsistent layouts. Either use one subagent for a series or explicitly share the template HTML.
