PERSONAL:
FACT: Whisnap is a macOS voice-to-text tool with two tiers:
- FREE LOCAL: Whisper/Parakeet models, 100% offline, batch processing, OS auto-paste, Fn key activation
- CLOUD ($10/mo): AI refinement strips filler, fixes structure, adapts output to context (detects Slack vs Gmail vs VS Code, applies personal vocabulary/snippets/dictionary)
- COMMAND MODE: Highlight text + Fn+Tab → speak instruction → LLM transforms text in-place

CONTEXT:
- User/founder: Marketing background, couldn't code 9 months ago, built it for their own workflow
- 10 Daily Active Users, $0 marketing spend
- Competitors: Superwhisper, MacWhisper (local tools), WisprFlow (cloud, $96/yr)
- Key differentiator: Context-aware output adaptation — same voice input becomes different text based on destination app
- Whisnap uses Whisper and Parakeet models (local tier)
- Source code: /Users/ned/Desktop/Projects/whisnap/

AFFECTS: When working on pitch deck or marketing content, lead with the context-adaptation differentiator (Slack vs Gmail vs code), not just 'voice to text'. The honest story (solo founder, 9 months learning to code, 10 DAUs) is the strength, not a weakness.
