DEBUG:
 SYMPTOM: build.js throws 'Text element <p> has background. Backgrounds, borders, and shadows are only supported on <div> elements, not text elements.'
 CAUSE: Styling like background, border, border-radius on text elements (<p> etc.) violates html2pptx validation
 FIX: Move background/border/padding styles from <p>/<span> to parent <div>. Keep only color/font/text-align on text elements.
 PREVENT: When writing slide HTML, always check: if a <p> has a background-like style, wrap it in a <div> with those styles instead
 OTHER RULES: Web-safe fonts only (Arial, not Inter/Inter). No CSS gradients. Body must be 720pt × 405pt. Run with NODE_PATH=/opt/homebrew/lib/node_modules.
