WHAT: capture.mjs supports both GIF and MP4 output with per-config format flag
WHERE: /Users/ned/Desktop/Projects/whisnap-brand/gifs/capture.mjs

MP4 FFMPEG FLAGS:
- libx264, CRF 18 (high quality), preset slow
- movflags +faststart (web playback)
- pix_fmt yuv420p (compatibility)
- scale with lanczos to target resolution

TARGET RESOLUTIONS:
- 16:9 HTML 800x450 (2x DPR = 1600x900 frames) → 1920x1080 MP4
- 4:3 HTML 800x600 (2x DPR = 1600x1200 frames) → 1440x1080 MP4
- 1:1 HTML 800x800 (2x DPR = 1600x1600 frames) → 1080x1080 MP4

CONFIG OBJECT KEYS: name, file, width, height, fps, duration, loop, format ('gif'|'mp4')

CLI FILTER: node capture.mjs terminal-mock
- Filters configs where name includes the substring
- Allows running single variants without editing the script

OUTPUT FILES: Same name as config .name field + .gif or .mp4 extension
