DEBUG:
SYMPTOM: Every attempt to get Remotion animations into Google Slides/PPTX failed

ATTEMPTS TRIED AND WHY THEY FAILED:
1. html2pptx workflow → Created slides from scratch in HTML/CSS that looked nothing like Remotion visuals. Completely wrong.
2. Rendered PNG keyframes → Assembled into PPTX with pptxgenjs. Visually correct but zero animations — just static images at 3 keyframes per slide.
3. Embedded MP4 videos (via pptxgenjs addMedia) → Works in PowerPoint desktop. Google Slides strips embedded audio/video entirely on import.
4. GIF conversion (ffmpeg two-pass palette, 960x540, 15fps) → Google Slides auto-plays GIFs natively, BUT quality was terrible and files were large, user rejected.

FIX: Single-file HTML presenter (pitch-deck.html) with CSS keyframe animations replicating the Remotion motion. Arrow key navigation, speaker notes toggle.

PREVENT: Do not attempt PPTX export for animated Remotion content destined for Google Slides. The HTML presenter IS the presentation format.
