WHAT: FluidAudioTranscriber/ is a Swift package that build.rs compiles with `swift build` when the `fluidaudio` feature flag is enabled. The resulting static lib is linked into Rust via FFI in fluidaudio_ffi.rs.
WHERE: FluidAudioTranscriber/ at project root, build.rs lines 64-72
HOW: `cargo build --features fluidaudio` triggers swift build automatically
WHY: CoreML inference must be done in Swift/Objective-C; Rust calls across FFI boundary
GOTCHA: FluidAudioTranscriber/.build/ is 727MB of Swift build cache — must be in .gitignore. Was not gitignored until this session (added in fc415b7).
