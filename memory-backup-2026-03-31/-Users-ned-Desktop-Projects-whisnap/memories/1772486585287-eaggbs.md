PATTERN: macOS transcription app with dual transport (WebSocket + HTTP POST /transcribe multipart)

COMPONENTS:
- WebSocket layer: handles start_transcription payload, mode, language fields
- HTTP layer: POST /transcribe with multipart form body
- Cloud strategy: central transcription execution path, builds options from payload fields
- Execution context / orchestrator: assembles context passed into cloud strategy
- System integration service: accessed from transcription layer, handles app/OS integration
- Accessibility layer: check_fn_accessibility() → AXIsProcessTrusted(); AXUIElement for field reads
- NSWorkspace: source for bundleIdentifier (frontmostApplication?.bundleIdentifier)

WHY: Per-app context (bundleId + appContext) must flow from transport layer → cloud strategy options → wherever formatting/vocab/style logic will live

REJECTED: No new OS permissions — work within existing accessibility grant state
