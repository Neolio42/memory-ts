WHAT: Current production distribution flow for Whisnap outside App Store

HOW:
- Signing identity: Developer ID Application certificate (outside-App-Store specific)
- No sandbox: entitlements have sandbox commented out ('<!-- Temporarily remove sandbox -->')
- Build: cargo tauri build → .dmg + .app.tar.gz (for updater)
- Notarization: test-signing-only.sh handles Apple notarization
- Updates: Tauri built-in updater hitting api.whisnap.com/releases/update
- Output: DMG downloaded from website

WHY: App sandbox is incompatible with global hotkeys and paste-to-active-app

GOTCHA: macOSPrivateApi: true in tauri.conf.json - would need to be removed for App Store but is fine for direct distribution
