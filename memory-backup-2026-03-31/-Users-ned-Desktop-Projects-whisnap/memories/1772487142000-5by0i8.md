DEBUG: Download failed with 'IO error: No such file or directory (os error 2)' for CoreML model files.

SYMPTOM: Model directory was created but nested subdirectories weren't, so writing Encoder.mlmodelc/weights/weight.bin failed.

CAUSE: individual_downloader.rs created the model root directory but not nested subdirectories for paths like Encoder.mlmodelc/weights/.

FIX (src-tauri/src/features/model_management/individual_downloader.rs — applied to all 4 variants of download_single_file):
```rust
// Ensure parent directories exist for nested paths (e.g., Encoder.mlmodelc/weights/)
if let Some(parent) = file_path.parent() {
    tokio::fs::create_dir_all(parent).await?;
}
```
Added before each file write operation across all 4 function variants.

PREVENT: CoreML .mlmodelc bundles always have nested directory structure. Any downloader handling manifest-based multi-file downloads must recursively create parent dirs.
