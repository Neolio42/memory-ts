WHAT: SystemIntegrationService::capture_frontmost_app_context() returns (Option<String>, Option<AppContext>) — bundle ID from NSWorkspace, rest from AXUIElement in single session.

WHERE: src-tauri/src/features/system_integration/service.rs

HOW:
- Calls get_frontmost_bundle_id() (NSWorkspace, always works)
- If AXIsProcessTrusted() → gets frontmost app PID, AXUIElementCreateApplication(pid)
- Reads kAXFocusedWindowAttribute → kAXTitleAttribute (window_title)
- Reads kAXFocusedUIElementAttribute → kAXValueAttribute (input_field_content)
- Reads kAXFocusedUIElementAttribute → kAXSelectedTextAttribute (cursor_context)
- Returns (None, None) on non-macOS
- Never prompts for accessibility permission
- Truncates window_title to 500 chars, input_field_content to 2000 chars

DEBUG: `npm run tauri:context` shows log:
```
Captured frontmost app context, bundle_id=Some("com.apple.mail"), window_title=Some("Re: Q3 Budget"), input_field_content=Some("Dear Sarah..."), cursor_context=None
```

WHY: Single AX session is more efficient than multiple calls. AX check prevents silent permission prompts.
