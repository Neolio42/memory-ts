INSIGHT: The two features that define Whisnap - global hotkey capture and paste-into-active-app - both require Accessibility APIs categorically prohibited in App Sandbox.

HARD BLOCKERS (no entitlement or exception exists):
1. CGEventTap (global hotkey) - FnKeyHelper/Sources/FnKeyHelper.swift:417-424 - system-wide event tap requires Accessibility, impossible in sandbox
2. Keystroke simulation (auto-paste) - paste_handler.rs:148-161, hotkeys/service.rs:439-476 - Enigo uses CGEventPost to simulate Cmd+V into other apps, requires Accessibility
3. AXIsProcessTrusted - commands/permissions.rs:111-119, FnKeyHelper.swift:116 - API unavailable in sandbox
4. IOHIDManager (keyboard detection) - FnKeyHelper.swift:545-578 - direct HID manager opens by vendor ID, blocked in sandbox
5. CGEventSource.keyState - FnKeyHelper.swift:154 - hardware key state query requires Accessibility

CONTEXT: This is why Alfred, Raycast, TextExpander, Keyboard Maestro all distribute outside App Store.

RECOMMENDATION: Stay with direct distribution. Current notarized DMG + Tauri updater flow is the industry standard for keyboard/utility apps.
