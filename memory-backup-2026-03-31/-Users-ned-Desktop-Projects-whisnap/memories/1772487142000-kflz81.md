DEBUG: Model downloads appeared to start but showed no progress, and cancel returned 'No active download found'.

SYMPTOM: No model_download_completed or model_download_error events reached frontend. Cancel command failed because task had already cleaned up.

CAUSE: The spawned download task in service.rs called remove_download() on completion but never called app_handle.emit() for completion/error events.

FIX (src-tauri/src/features/model_management/service.rs, inside tokio::spawn block):
```rust
match &result {
    Ok(()) => {
        let _ = download_manager.remove_download(&model_id_clone).await;
        let _ = app_handle.emit("model_download_completed", &model_id_clone);
    }
    Err(e) => {
        let _ = download_manager.remove_download(&model_id_clone).await;
        let error_payload = serde_json::json!({
            "model_id": model_id_clone,
            "error": e.to_string(),
        });
        let _ = app_handle.emit("model_download_error", error_payload);
    }
}
```

PREVENT: Always emit events from within the spawned task that has the final result, not from the outer async fn that initiates it.
