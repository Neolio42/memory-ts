PATTERN: Before pushing, run all 5 CI steps locally to catch failures
WHEN: Before any git push to main
WHY: CI on GitHub runs these exact steps; local validation prevents broken builds

The 5 CI steps:
1. npm run lint (ESLint)
2. npx tsc --noEmit (TypeScript check)
3. cargo check --features fluidaudio (NOT --features sherpa — that was the old backend)
4. npm test (Vitest — 2,631 tests across 78 suites)
5. cargo test --lib (Rust unit tests — 399 tests, excludes integration tests needing hardware)

NOTE: cargo test excludes pipeline_performance tests (need real audio hardware)
