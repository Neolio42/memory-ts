FACT: Whisnap is a macOS-first (Apple Silicon M1-M4) Tauri v2 desktop application written in Rust for real-time local speech-to-text transcription.

CONTEXT:
- Primary backend: whisper-rs (whisper.cpp Rust bindings) — working
- Secondary backend: sherpa-rs (sherpa-onnx Rust bindings) for Parakeet TDT models — partially integrated
- Target: macOS 11+, Apple Silicon M-series
- Audio format: 16kHz mono f32
- Performance target: real-time factor < 0.5x (10s audio transcribed in <5s)
- Model format: ONNX (encoder/decoder/joiner + tokens.txt from HuggingFace sherpa-onnx repos)

AFFECTS: All transcription architecture decisions, performance targets, and library choices are shaped by macOS/Apple Silicon/Tauri constraints
