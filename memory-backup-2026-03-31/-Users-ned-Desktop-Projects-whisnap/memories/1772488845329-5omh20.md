DECISION: Use sherpa-rs = "0.6.8" from crates.io instead of git branch = "main"

OPTIONS:
- Keep git branch = "main" (current, unstable)
- Pin to v0.6.8 crates.io release (recommended)
- Switch to parakeet-rs, ort, or transcribe-rs (all rejected)

REASONING:
- sherpa-rs now has frequent tagged releases: v0.6.3 (Jan 18), v0.6.5 (Jan 19), v0.6.6 (Feb 25), v0.6.8 latest
- Perfect model compatibility with sherpa-onnx HuggingFace model files (encoder.int8.onnx, decoder.int8.onnx, joiner.int8.onnx, tokens.txt)
- Full TDT decoder from k2-fsa reference implementation (the model authors themselves)
- parakeet-rs (altunenes) has broken CoreML, unverified TDT quality
- jason-ni/parakeet-rs abandoned, author moved to MLX
- transcribe-rs: not production-ready, single maintainer
- ort direct: requires implementing entire TDT greedy decode loop yourself

REVISIT WHEN: ONNX Runtime ships Metal/MPS support, or MLX gets Rust bindings
