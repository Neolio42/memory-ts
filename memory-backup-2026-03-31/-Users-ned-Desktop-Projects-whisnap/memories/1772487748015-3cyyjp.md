WHAT: Debug npm script for Parakeet performance profiling added to package.json

COMMAND: npm run tauri:parakeet

SETS LOG FILTERS:
- inference::parakeet=trace — every timing: model load, warmup, chunk processing, decode calls, processing_time_ms
- transcription::dynamic=debug — confirms DynamicTranscriber routing to parakeet backend
- model::loading=debug — model resolution and cache hits/misses
- model::resolution=debug — backend_id lookup

USE WHEN: Investigating Parakeet transcription performance, timing breakdowns, routing issues

KEY TIMINGS IN LOGS:
- 'Starting transcription, duration_minutes=X' → 'Transcription completed, processing_time_ms=Y'
- 'Resolved backend for active model, backend_id=parakeet' → confirms routing
