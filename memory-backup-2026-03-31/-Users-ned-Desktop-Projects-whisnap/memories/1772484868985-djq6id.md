WHAT: Fixed the hotkey warning banner to show which specific shortcut failed to register, instead of generic 'A hotkey shortcut couldn't register'.

WHERE: src/components/atoms/HotkeyStatusBanner.tsx

HOW: The backend already emits strings like 'Recording hotkey failed to register' and 'Toggle recording hotkey failed to register'. The banner now extracts the shortcut name from these strings and displays e.g. 'Push-to-talk shortcut couldn't register' or 'Toggle recording shortcut couldn't register'.

WHY: Original message was useless — users couldn't tell which of their keybinds had a conflict.
