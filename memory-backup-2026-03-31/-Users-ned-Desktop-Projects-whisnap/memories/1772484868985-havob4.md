WHAT: Added a small clear button to each KeybindInput that sets the keybind to "" (empty/disabled), calling onChange("") to persist the change.

WHERE: src/components/molecules/KeybindInput.tsx, src/components/molecules/KeybindInput.css.ts

HOW: Renders an × button next to the keybind display. Only visible when a keybind is set (non-empty). Clicking calls onChange(""). The backend already handles empty keybinds by skipping registration.

WHY: Without clear, swapping keybinds (e.g. move PTT from FN to FN+Space) was blocked by duplicate detection. Now: clear one → set the other → set the first.

GOTCHA: The button is only rendered when the current value is non-empty, so there's no way to "clear" an already-empty keybind.
