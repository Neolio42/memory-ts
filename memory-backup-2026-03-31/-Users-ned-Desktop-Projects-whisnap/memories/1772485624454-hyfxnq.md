WHAT: bundleId (NSWorkspace) and appContext (AXUIElement) captured at recording start, flow through ExecutionContext → CloudTranscribeOptions → WebSocket StartTranscriptionConfig JSON and HTTP multipart form.

WHERE:
- Capture: src-tauri/src/features/system_integration/service.rs → capture_frontmost_app_context()
- Storage: src-tauri/src/features/transcription/strategy_traits.rs → ExecutionContext fields
- Builder: src-tauri/src/features/transcription/context_builder.rs → with_app_info()
- Capture site: src-tauri/src/features/transcription/service.rs ~line 763 (live) and ~line 1291 (command)
- Cloud strategy: src-tauri/src/features/transcription/strategies/cloud_stream_strategy.rs (3 sites)
- WebSocket: src-tauri/src/features/inference/backends/cloud/websocket_client.rs
- HTTP: src-tauri/src/features/inference/backends/cloud/api_client.rs

HOW:
```rust
// In service.rs at recording start:
let sys_service = SystemIntegrationService::new_for_detection();
let (bundle_id, app_context) = sys_service.capture_frontmost_app_context();
// Then: builder.with_app_info(bundle_id, app_context)

// HTTP form (api_client.rs):
if let Some(bundle_id) = &options.bundle_id {
    form = form.text("bundleId", bundle_id.clone());
}
if let Some(app_context) = &options.app_context {
    let json = serde_json::to_string(app_context)
        .map_err(CloudTranscriptionError::JsonError)?;
    form = form.text("appContext", json);
}
```

WHY: Server uses bundleId for per-app formatting, vocab learning, style fingerprinting. appContext fields give additional context.

GOTCHA: AppContext struct has 5 optional fields but currently only window_title, input_field_content, cursor_context are populated. threadContext and fileLanguage are defined but always None.
