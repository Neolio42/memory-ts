DECISION: Remove ModelFormat::SdkManaged, switch FluidAudio to ModelFormat::Manifest
OPTIONS: Keep SdkManaged with fake 5% timer progress; or unify with manifest system
REASONING: SdkManaged had no real progress, no cancel, no pause/resume, completely different download path from Whisper/Parakeet. FluidAudio SDK v0.12.1 has AsrModels.load(from:) for offline loading, so we can download HuggingFace files ourselves and point SDK at local directory.
IMPACT: All SdkManaged branches removed from service.rs (validate_downloaded_model, check_model_exists, get_model_status, download_model, cleanup_partial_download). dir_size_recursive function removed (was only used by SdkManaged). ModelManifestFormat::CoreML variant added.
REVISIT WHEN: If AsrModels.load(from:) requires pre-compiled models from SDK cache rather than raw HuggingFace files.
