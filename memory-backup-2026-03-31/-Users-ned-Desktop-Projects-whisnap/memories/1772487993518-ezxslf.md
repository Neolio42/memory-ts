TECHNICAL:
  WHAT: fluidaudio.rs load_model() now caches the loaded version in a static OnceLock<Mutex<Option<String>>>. If the same version is already loaded, returns immediately without FFI call.
  WHERE: src-tauri/src/features/inference/backends/fluidaudio.rs
  HOW:
    static LOADED_VERSION: OnceLock<Mutex<Option<String>>> = OnceLock::new();
    
    pub async fn load_model(model_id: &str) -> Result<()> {
        let version = version_from_model_id(model_id);
        {
            let lock = loaded_version_lock();
            if let Ok(guard) = lock.lock() {
                if guard.as_deref() == Some(version) {
                    return Ok(()); // already loaded
                }
            }
        }
        // ... real FFI call ...
        // After success, update cache:
        if let Ok(mut guard) = loaded_version_lock().lock() {
            *guard = Some(version.to_string());
        }
    }
  WHY: FluidAudioTranscriber calls load_model before every transcription. Swift SDK caches internally but the FFI overhead was wasteful.
  GOTCHA: If model is switched (v2 ↔ v3), the cache correctly detects the version mismatch and re-loads.
