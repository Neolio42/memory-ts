SYMPTOM: FluidAudio download failed with 'IO error: No such file or directory (os error 2)'
CAUSE: individual_downloader.rs download_single_file() only created the top-level model_dir (e.g., models_dir/parakeet-tdt-0.6b-v3-coreml/) but not subdirectories for nested paths like Encoder.mlmodelc/weights/
FIX: Added tokio::fs::create_dir_all(file_path.parent().unwrap()) before File::create in ALL 4 variants of download_single_file in individual_downloader.rs
PREVENT: When adding new manifest types with nested directory structures, ensure parent dir creation is in place. The fix now handles all nested paths correctly.
WHERE: src-tauri/src/features/model_management/individual_downloader.rs — 4 variants of download_single_file (static, non-static, and their cancellation counterparts)
