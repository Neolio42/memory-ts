WHAT: FluidAudio CoreML .mlmodelc directories contain specific files with specific sizes
WHERE: manifest.rs — create_fluidaudio_v3_manifest(), create_fluidaudio_v2_manifest()
HOW: Each .mlmodelc has: weights/weight.bin (the bulk of data), weights/weight.bin.index (tiny), coremldata.bin (~400-600 bytes GENUINE, not LFS pointer), metadata.json (tiny), model.mil (tiny), analytics/coremldata.bin (tiny). Plus parakeet_vocab.json at root.
WHY: Must download ALL files including tiny metadata to satisfy AsrModels.load(from:)
GOTCHA: coremldata.bin appears to be ~485 bytes (looks like LFS pointer size) but is genuinely small — NOT an LFS pointer. Actual weights are ONLY in weights/weight.bin.
