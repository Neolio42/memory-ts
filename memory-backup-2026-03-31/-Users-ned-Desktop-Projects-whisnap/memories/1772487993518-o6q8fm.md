DEBUG:
  SYMPTOM: HuggingFace API tree returns total file size of ~1MB for parakeet-tdt-0.6b-v3-coreml, but model is actually ~500MB+
  CAUSE: All *.bin files in the repo are Git LFS tracked (.gitattributes confirms). The API returns metadata/pointer file sizes (485 bytes = the LFS pointer text), not the actual binary sizes.
  FIX: To get real file sizes for manifests, use HEAD request on LFS resolve URL:
    https://huggingface.co/FluidInference/parakeet-tdt-0.6b-v3-coreml/resolve/main/<filename>
    The Content-Length header returns the real file size.
  VERIFIED BY: Fetching raw content of Encoder.mlmodelc/coremldata.bin returns:
    'version https://git-lfs.github.com/spec/v1\noid sha256:<hash>\nsize <actual_bytes>'
  PREVENT: When creating manifest entries for HuggingFace-hosted models, always use the LFS resolve URL pattern, not the tree API sizes.
