TECHNICAL: Hardcoded fallback model ID whitelist in settings/service.rs updated.

WHERE: src-tauri/src/features/settings/service.rs ~line 326-327

WHAT CHANGED:
- Old: 'parakeet-tdt-0.6b-v2-int8', 'parakeet-tdt-0.6b-v2-fp16' (sherpa ONNX models)
- New: 'parakeet-tdt-0.6b-v3-coreml', 'parakeet-tdt-0.6b-v2-coreml' (FluidAudio CoreML models)

This list is used when the model registry fails to load — settings are validated against this whitelist to prevent corruption. If a user had the old sherpa models selected, their settings would be reset on next load.
