PATTERN: The 5 keybinds fall into distinct categories based on how they handle FN:

| Keybind | FN support | Handler | Swappable? |
|---|---|---|---|
| Push-to-talk | Bare FN only | `handle_fn_key_event` (hardcoded) | No |
| Toggle recording | FN+key only | `handle_shortcut_event` (hardcoded) | No |
| Cancel | Non-FN only | `global_shortcut` via `register_cancel_hotkey` | Breaks if set to FN |
| Paste transcript | Non-FN only | `global_shortcut`, no `is_fn_keybind` check | Breaks if set to FN |
| Command mode | Both | Has `is_fn_keybind` check + FN coordinator support | Partially works |

WHY: Cancel and Paste use `.parse::<Shortcut>()` which cannot parse 'FN' or 'FN+Space'. If assigned FN-based keybinds, they silently fail and add 'failed to register' status issues.

Command mode is the reference implementation — it checks `is_fn_keybind` and has both global shortcut and FN coordinator paths.
