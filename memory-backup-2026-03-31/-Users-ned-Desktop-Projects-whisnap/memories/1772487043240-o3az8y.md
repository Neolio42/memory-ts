WHERE: service.rs delete_model(), commands/models.rs delete_model command, lib.rs registration
HOW (backend logic):
  1. Check model_id != BUNDLED_MODEL_ID ("ggml-base.en-q5_1")
  2. Get model definition via resolver
  3. Match ModelFormat: Manifest → remove_dir_all(model_dir), SingleFile → remove_file(file_path)
  4. emit('model_deleted', model_id)
  5. model_resolver.invalidate_cache()

  - window.confirm before proceeding
  - onDelete prop wired: ModelCard ← ModelCategorySection ← ModelBrowser ← ModelsSection ← SettingsPage (from store)
