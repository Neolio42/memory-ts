TECHNICAL: Privacy-safe Logging for AX Capture

WHAT: The debug log for captured frontmost app context shows field lengths, NOT values:
```rust
debug!(
    target: "system::integration",
    bundle_id = ?bundle_id,
    window_title = ?window_title,
    input_field_len = input_field_content.as_ref().map(|s| s.chars().count()),
    cursor_context_len = cursor_context.as_ref().map(|s| s.chars().count()),
    "Captured frontmost app context"
);
```

WHY: window_title is acceptable (app name, not content). input_field_content and cursor_context contain user-typed text — passwords, API keys, chat messages. These must never appear in log files, even at DEBUG level.

GOTCHA: The user initially WANTED actual content in logs (to verify capture was working). The audit flagged this as a privacy violation. The compromise: show lengths to confirm capture is working without revealing content.
