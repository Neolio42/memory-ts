PATTERN: DynamicTranscriber wraps both WhisperTranscriber and ParakeetTranscriber, holds Arc refs to both, routes in transcribe() based on active model's backend_id

WHERE: src-tauri/src/features/transcription/components/transcribers/dynamic_transcriber.rs

HOW:
- transcribe(): calls settings_service to get model_id → calls model_file_service.get_backend_id_by_model_id(model_id) → match backend_id { "whisper" => whisper.transcribe(), "parakeet" => parakeet.transcribe() }
- name(): "dynamic"
- supports_streaming(): delegates to active backend

WHY: Orchestrator is created ONCE at startup (transcription_services.rs:57) and never rebuilt when user switches models. Factory selection at startup-time would lock the backend. DynamicTranscriber makes the routing decision per-transcription call.

EXTENDING: To add FluidAudio, add a third arm: "coreml-parakeet" => fluid_audio.transcribe(). The DynamicTranscriber holds an Option<FluidAudioTranscriber> gated on #[cfg(target_os = "macos")].
