WHAT: FluidAudio Swift package resolves to v0.12.1 despite Package.swift specifying from: "0.7.9"

ACTUAL API:
```swift
// Type name: AsrModelVersion (NOT AsrVersion)
let asrVersion: AsrModelVersion = version == "v2" ? .v2 : .v3

// Download + load
let models = try await AsrModels.downloadAndLoad(version: asrVersion)

// Initialize manager  
let mgr = AsrManager(config: .default)
try await mgr.initialize(models: models)

// Transcribe
let result = try await mgr.transcribe(samples)  // samples: [Float]
return result.text  // ASRResult.text: String
```

WHERE: SDK source at .build/checkouts/FluidAudio/ in src-tauri/

GOTCHA: AsrConfig.default works. Transcribe takes [Float] (f32), not i16 — must convert: `sample as f32 / 32768.0`
GOTCHA: Actor-based singleton AsrManagerHolder needed for thread-safe manager reuse across transcriptions
