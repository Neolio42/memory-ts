Investigated how Whisnap's auto-update system works: it uses Tauri's updater plugin hitting a backend endpoint, with pre-signed Backblaze B2 URLs for binary downloads. Discovered that production GitHub Actions CI builds were shipping with the staging updater endpoint hardcoded (staging.api.whisnap.com) because the sed-patch from the local build script was never added to release.yml. Fixed by adding the sed patch to release.yml and committing, so v1.0.6 will self-correct the endpoint for all future users.
