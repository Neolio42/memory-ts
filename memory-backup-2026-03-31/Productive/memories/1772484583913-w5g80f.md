FACT: User shared a GitHub PAT token in plain text in the chat session. Token was set as GITHUB_TOKEN environment variable in /root/.bashrc on the VPS.

ACTION TAKEN: User was warned the token was exposed in chat and should rotate it.

AFFECTS: If the token hasn't been rotated, it may still be valid. On future sessions if the user mentions GitHub auth issues on the VPS, this is the likely cause.

NOTE: gh CLI cannot create PATs - must be done via github.com → Settings → Developer settings → Personal access tokens
