WHAT: LM Studio serves Qwen 3.5 9B (Q4_K_M GGUF) at localhost:1234 with OpenAI-compatible API.
HOW: Disable thinking mode via assistant prefill to get clean JSON output:
```python
messages = [
  {"role": "system", "content": system_prompt},
  {"role": "user", "content": content},
  {"role": "assistant", "content": "<think>\n</think>\n"}  # Skips thinking
]
```
PARAMS: temperature=0.1 (deterministic), max_tokens=200 (sufficient for JSON). One item at a time - Qwen gets confused with batches.
WHY: Without prefill, model outputs reasoning before JSON making extraction brittle. With prefill: clean JSON, 5x faster.
GOTCHA: Cannot disable thinking via API parameters - the prefill trick is the only way through the OpenAI-compat endpoint.
