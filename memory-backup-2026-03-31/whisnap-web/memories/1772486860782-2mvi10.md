WHAT: whisnap CLI for command-line audio/video transcription
INSTALL: Settings → Advanced → toggle 'CLI Tool', symlinks to /usr/local/bin/whisnap (prompts admin password)
USAGE: whisnap <FILE> [flags]

FLAGS:
  --cloud / -c       Use cloud transcription (requires app sign-in)
  --model <ID> / -m  Override Whisper model (e.g. small-q5_1), can't combine with --cloud
  --json / -j        Output structured JSON instead of plain text
  --verbose / -v     Print progress/diagnostics to stderr
  --list-models      Show all models with sizes, then exit
  --help             Help text with examples
  --version          Print version

SUPPORTED FORMATS:
  Audio: WAV, MP3, FLAC, M4A/AAC, OGG
  Video: MP4, MOV, MKV, WebM (audio track extracted)
