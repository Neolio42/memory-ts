WHAT: Platform naming convention for the Tauri auto-update system

FORMAT: {target}-{arch} — e.g., darwin-aarch64, windows-x86_64, linux-x86_64

WHERE IT COMES FROM:
  - S3 folder structure: releases/v1.0.5/darwin-aarch64/
  - scanS3ForReleases() reads folder names directly → always full arch name
  - tauri.conf.json sends {target}-{arch} as the platform param

EXACT MATCH in getUpdate(): platform === release.platform
  This works because Tauri sends the full name AND S3 stores the full name

PARTIAL MATCH in getDownloadUrl() + getLatestRelease():
  r.platform === platform || r.platform.startsWith(platform)
  This is intentional — download endpoint accepts bare 'darwin' for convenience

GOTCHA: Don't 'fix' the exact match in getUpdate() — it's correct. The partial match elsewhere is for download convenience, not updates.
