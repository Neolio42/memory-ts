FACT: Whisnap is a Mac desktop application for speech-to-text / voice dictation. Built on Next.js.

CORE DIFFERENTIATOR: Offline/local processing — no cloud upload, privacy-first. This is the key selling point vs Otter AI, Google Docs voice typing, and other cloud-dependent tools.

CURRENT PAGES (24 routes): Homepage, /pricing, /blog (1 article), /download, /support, legal pages, auth flow, /dashboard, /admin.

TARGET USER SEGMENTS identified from keyword research:
1. Mac users looking for Apple Dictation alternative
2. Developers wanting voice input while coding
3. Writers doing long-form content dictation
4. People with RSI/carpal tunnel needing hands-free typing
5. Professionals needing meeting transcription
6. Privacy-conscious users who don't want cloud processing

COMPETITORS referenced in keyword strategy:
- Apple Dictation (built-in Mac, limited)
- Otter AI (cloud-based, not desktop)
- Google Docs voice typing (browser-only)
- Dragon Dictation (Windows-focused, expensive)
- SuperWhisper (direct competitor)
- Whisper Desktop (open source)

TECH STACK: Next.js app with App Router, TypeScript, existing sitemap.ts and metadata patterns in page files.
