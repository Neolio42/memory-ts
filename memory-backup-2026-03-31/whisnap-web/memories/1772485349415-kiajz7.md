SYMPTOM: Learning system was analyzing its own LLM-formatted output to 'learn' user style — circular feedback that just reinforced whatever defaults we started with.

CAUSE: DB query in fingerprint generator selected `llmOutput` instead of `transcript`.

FIX: Changed query in fingerprint-generator to select `transcript` (raw speech). Updated prompt to analyze speech patterns rather than polished writing. LLM correctly detects formality/tone from raw speech vocab ('dear team', 'kindly confirm') even without punctuation.

PREVENT: Always analyze the USER's input signal, not the system's own output. Raw transcript = real signal about how the user communicates. LLM output = echo of our own defaults.
