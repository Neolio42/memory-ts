WHAT: TranscriptionHistory model has two critical fields:
- `transcript`: raw ASR output (what the speech engine heard)
- `llmOutput`: final LLM-enhanced output (what got pasted)

WHY THIS MATTERS: The diff between these two fields is the vocabulary learning signal. No new data collection infrastructure needed. Every transcription already captures both ends of the pipe.

WHERE: TranscriptionHistory table in the cloud database (confirmed via codebase exploration).

GOTCHA: bundleId is NOT currently stored on TranscriptionHistory. It needs to be added in Phase 0 schema migration to enable per-app scoping of vocabulary and style fingerprinting.
