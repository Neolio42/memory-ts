WHAT: Standard page structure for all Whisnap marketing/SEO pages
WHERE: All pages under app/ (use-cases/, compare/, speech-to-text-mac/)
HOW:
```tsx
import { getSEOTags } from '@/libs/seo';
import Layout from '@/components/layout/Layout';
import Script from 'next/script';

export const metadata = getSEOTags({ title: '...', description: '...', canonicalUrlRelative: '/path' });

export default function Page() {
  const jsonLd = { /* BreadcrumbList, FAQPage, or SoftwareApplication schema */ };
  return (
    <Layout>
      <Script type="application/ld+json">{JSON.stringify(jsonLd)}</Script>
      {/* page content */}
    </Layout>
  );
}
```
WHY: Consistent SEO metadata generation and schema markup across all pages
GOTCHA: ESLint `react/no-unescaped-entities` — ALL apostrophes must be `&apos;` and quotes `&quot;` in JSX text. Build will fail otherwise. Previous session fixed this with a bulk regex script.
