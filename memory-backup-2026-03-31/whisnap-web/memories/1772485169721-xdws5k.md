BUG:
SYMPTOM: Common English words like 'Hello', 'Computer', 'World' (capitalized) are being learned as vocabulary terms.

CAUSE: `extractVocabCandidates()` only calls `isCommonCorrection()` for words that already passed `isLikelySpecialTerm()`. But `isCommonCorrection()` skips the common-words lookup when `isLikelySpecialTerm(corrected)` is true. So any word that reaches `isCommonCorrection` will never hit the common-words filter.

FIX: Restructure `isCommonCorrection` to NOT guard the common-words check with `!isLikelySpecialTerm()`. The common-words check should be independent — a capitalized common word (like 'Computer') should still be rejected.
