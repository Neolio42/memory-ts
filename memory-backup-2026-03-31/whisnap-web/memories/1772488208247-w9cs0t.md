TECHNICAL: app/sitemap.ts structure after expansion

WHAT: Dynamic sitemap that generates blog routes from content.tsx + static routes for all landing pages

WHERE: app/sitemap.ts

HOW:
```typescript
import { articles } from "@/app/blog/_assets/content";

const blogRoutes = articles.map(article => ({
  url: `${baseUrl}/blog/${article.slug}`,
  lastModified,
  changeFrequency: "monthly" as const,
  priority: 0.7,
}));
```

- Homepage: 1.0
- /speech-to-text-mac: 0.9
