BUG:
SYMPTOM: After 500 transcriptions saying 'Kubernetes' with same ASR error, rawVariants array has 500 copies of 'kubrntes'.

CAUSE: `learnFromTranscription()` upserts with `rawVariants: { push: candidate.rawVariant }` every time, even if the variant is already present.

FIX: Either:
  Option A: Dedup before push — check if rawVariant already in array, skip if so
  Option B: Cap the array — only push if rawVariants.length < N (e.g., 10 unique variants)
  Recommended: Option A (dedup) — `rawVariants: { set: Array.from(new Set([...existing.rawVariants, candidate.rawVariant])) }`
