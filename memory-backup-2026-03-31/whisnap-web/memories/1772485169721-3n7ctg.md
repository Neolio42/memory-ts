BUGS (HIGH PRIORITY — from audit session):

1. CASE-SENSITIVE DEDUP: `seenTerms` Set in `extractVocabCandidates` uses raw case — 'TypeScript' and 'typescript' both pass, creating two DB entries.
   FIX: Use `corrected.toLowerCase()` as the Set key.

2. MISSING CONTRACTIONS: These common ASR errors are missing from the contractions rejection list:
   - theyre → they're
   - youre → you're  
   - weve → we've
   - hes → he's, shes → she's
   - couldve → could've, shouldve → should've, wouldve → would've
   - theyve → they've
   FIX: Add these pairs to the CONTRACTION_PAIRS set.

3. INFLECTION MIN-LENGTH: `isInflectionChange` plural rule matches 'a' → 'as', 'I' → 'Is'.
   FIX: Add guard `if (word.length < 3) return false` at start of `isInflectionChange`.
