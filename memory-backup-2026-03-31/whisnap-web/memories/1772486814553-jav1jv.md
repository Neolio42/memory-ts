FACT: Whisnap is a macOS speech recognition desktop app. Core: press hotkey anywhere, speak, transcribed text auto-pastes at cursor.

LOCAL MODE (free):
- Push-to-talk, toggle recording, file upload (WAV/MP3/FLAC/M4A/OGG/MP4/MOV/MKV/WebM)
- Multiple Whisper models (Tiny bundled, Base/Small/Medium/Large downloadable)
- Metal GPU acceleration, works fully offline
- Noise suppression, audio quality presets (Off/Natural/Accuracy)
- Mute media during recording, microphone selection

PRO/CLOUD MODE ($10/month):
- Cloud transcription with enhanced accuracy
- Context-aware AI formatting (cloud pipeline, not just raw transcription)
- Snippets: trigger→replacement text expansion (up to 100), auto-applied during transcription
- Custom Dictionary (up to 1000 words)
- Command Mode: select text → FN+Tab → speak command → text transforms in-place (needs LLM)
- Dashboard: transcription count, WPM average, weekly streak
- Quick Notes: dedicated recording with waveform visualization, segmented transcripts
- History: searchable archive, audio playback, reprocess with different models

SYSTEM:
- Menu bar icon, global hotkeys (work in fullscreen)
- Status overlay floating indicator
- Storage management: auto-compress/delete, FLAC compression
- CLI tool: /usr/local/bin/whisnap
- OAuth login, 7-day free trial
- Update channels: Stable/Latest/Beta
- Onboarding: 5 steps (welcome, mic permission, auto-paste, hotkey, quick start)

AFFECTS: Never claim GPT-4/Claude are user-facing model choices. Cloud Mode pipeline is abstracted — users don't pick 'GPT-4' from a dropdown. Command Mode is the killer differentiator (transform selected text with voice commands).
