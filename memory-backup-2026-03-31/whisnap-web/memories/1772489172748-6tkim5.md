WHAT: `authenticateUser` and `authenticateToken` are the same function — `export const authenticateUser = authenticateToken` (auth.ts:526). All authenticated routes use the same middleware chain.

WHERE: auth.ts:526, auth.ts:385

HOW: Auth flow on token validation:
1. Decode JWT (HS256, secret: JWT_SECRET || NEXTAUTH_SECRET)
2. UserCache.getUser(userId) → Redis check → Prisma fallback
3. If user null → 401 USER_NOT_FOUND
4. If token invalid → 401 INVALID_TOKEN

WHY: Unified auth path means any 401 has the same root causes regardless of endpoint.

GOTCHA: ForwardAuth Traefik middleware was removed Nov 2025. The IngressRoute for staging.api.whisnap.com goes directly to api-sticky with no auth middleware at ingress level.
