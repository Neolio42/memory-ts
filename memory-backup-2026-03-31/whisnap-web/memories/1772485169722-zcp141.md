WHAT: Background LLM call that analyzes the last 20 transcriptions for a user+bundleId and generates a 3-4 sentence style description saved to DestinationProfile.styleFingerprint.

WHERE: api/src/services/style-fingerprint.ts

HOW:
- Triggered in `runLearningHooks()` in unified-processor.ts after saveToDatabase
- `incrementTranscriptionCount()` upserts +1 on transcriptionsSinceFP
- `shouldGenerateFingerprint(count)` returns true at count >= 10, then resets to 0
- `generateStyleFingerprint(userId, bundleId)` queries 20 recent TranscriptionHistory rows, calls LLM, saves result
- FINGERPRINT_MODELS = ['llama-3.1-8b-instant', 'gemini-2.5-flash-lite'] — tries in order
- Fingerprint injected into system prompt via prompt-builder.ts

WHY: Groq is faster and cheaper as primary; Gemini as fallback if Groq unavailable. Fire-and-forget so it never blocks transcription.

GOTCHA: Requires bundleId to be present — won't fingerprint for requests without bundleId.
