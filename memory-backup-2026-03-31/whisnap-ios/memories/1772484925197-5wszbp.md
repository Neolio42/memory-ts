INSIGHT: When a view has rapid state transitions (recording → processing → done in <1s), animation completion blocks fire after state has already changed, causing wrong UI.

PATTERN — stateGeneration counter:
```swift
private var stateGeneration = 0

func animateToProcessing() {
    let generation = stateGeneration  // capture at start
    UIView.animate(withDuration: 0.25, animations: { 
        self.waveformStack.alpha = 0 
    }) { _ in
        guard self.stateGeneration == generation else { return }  // stale check
        self.showProcessingDots()
    }
}

func animateToDone() {
    stateGeneration += 1  // invalidate any in-flight animations
    // immediately hide waveform/dots in case processing animation still running
    waveformStack.alpha = 0
    dotsStack.alpha = 0
    // now animate done state...
}
```

APPLICATION: Used in RecordingOverlayView to prevent processing dots from appearing after done checkmark when transcription completes very quickly.
