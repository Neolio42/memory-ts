SYMPTOM: All keychain operations silently succeed (return errSecSuccess) but tokens can't be read back. App can't stay logged in, 401s on every request, sign-in button appears unresponsive because the token written can't be read.

CAUSE: `Bundle.main.infoDictionary?["AppIdentifierPrefix"]` returns nil at runtime — AppIdentifierPrefix is a build-time substitution variable only available in entitlements files. So accessGroup becomes just "com.whisnap.shared" (no team ID prefix), which is an invalid access group. Keychain rejects it.

FIX: Remove kSecAttrAccessGroup from all query dictionaries. Keep the keychain-access-groups entitlement in both .entitlements files for future use. When keyboard extension is added, use a hardcoded team ID or a build-injected Info.plist key, NOT Bundle.main.infoDictionary["AppIdentifierPrefix"].

PREVENT: Never use $(AppIdentifierPrefix) syntax as a runtime value. It only works in entitlements files at build time.
