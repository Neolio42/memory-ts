DEBUG
SYMPTOM: engine.start() fails with error 2003329396 after app backgrounding or interruption
CAUSE: AudioCaptureService warm engine reuse path calls engine.prepare() then startRecordingWithEngine() but never calls AVAudioSession.setActive(true). deactivateSession() (called on background transitions) sets setActive(false), leaving session inactive when warm path runs.
FIX: In warm engine path, add setCategory(.playAndRecord, mode:.measurement, options:[.defaultToSpeaker,.allowBluetooth,.allowBluetoothA2DP]) + setActive(true) before engine.prepare(). Wrap entire warm path in do/catch — if reactivation fails, nil out audioEngine/inputNode/cachedInputFormat/isSessionPrepared and fall through to full setup path.
PREVENT: Any code path that calls engine.start() must ensure AVAudioSession is active first. deactivateSession() and the warm engine path must be kept in sync.
