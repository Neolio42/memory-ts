SYMPTOM: extensionContext.open → false. URL scheme (whisnap-ios://relay) never opens.
CAUSE: extensionContext.open(_:) only works for Action/Share extensions, NOT keyboard extensions.
FIX: Walk the responder chain looking for UIApplication using responds(to:):
```swift
func openURL(_ url: URL) {
    let selector = #selector(UIApplication.open(_:options:completionHandler:))
    var responder: UIResponder? = self
    while let r = responder {
        if r.responds(to: selector) {
            let _ = r.perform(selector, with: url, with: [:])
            return
        }
        responder = r.next
    }
}
```
USE `responds(to:)` not `canPerformAction(_:withSender:)` — UIApplication implements openURL but doesn't advertise it as a UI action.
