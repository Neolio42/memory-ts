SYMPTOM: Notification fires before ContentView subscribes on cold launch → deep link lost. Attempted fix with @AppStorage but that persists to disk and survives app restarts, causing stale relay activation on next launch.

FIX in Whisnap_IOSApp.swift:
```swift
// Session-scoped — survives cold launch but not app restart
enum DeepLinkIntent {
    static var pending: String = ""
}

func handleIncomingURL(_ url: URL) {
    if url.host == "relay" {
        DeepLinkIntent.pending = "relay"  // store before posting
        NotificationCenter.default.post(name: .keyboardRequestedRelay, object: nil)
    }
}
```

In ContentView.swift:
```swift
.onAppear {
    if DeepLinkIntent.pending == "relay" {
        DeepLinkIntent.pending = ""
        showRelay = true
    }
}
```

WHY @AppStorage FAILS: @AppStorage("pendingDeepLink") writes to UserDefaults and persists. If app crashes after setting it but before clearing it, next launch incorrectly jumps to relay.
