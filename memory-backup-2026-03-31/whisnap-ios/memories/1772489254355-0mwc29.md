WHAT: Correct build command parameters for Whisnap iOS project

HOW:
```bash
# Build
xcodebuild -scheme Whisnap -destination 'platform=iOS Simulator,name=iPhone 17 Pro' -configuration Debug build 2>&1 | grep -E 'error:|warning:|BUILD'

# List available schemes
xcodebuild -list -workspace Whisnap-IOS/Whisnap-IOS.xcworkspace

# List available simulators
xcrun simctl list devices available
```

GOTCHA: Scheme is 'Whisnap' NOT 'Whisnap-IOS'. Available simulator is 'iPhone 17 Pro' with iOS 26 SDK, not iPhone 15/16.
