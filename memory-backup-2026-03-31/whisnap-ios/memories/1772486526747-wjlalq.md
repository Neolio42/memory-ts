WHAT: Python scripts that measure keyboard dimensions from screenshots by scanning pixel brightness to detect grey areas, key boundaries, and compute pt values (dividing px by 3.0 for @3x screens)

WHERE: Whisnap-IOS/tools/ (inside the repo at /Users/ned/Desktop/Projects/whisnap-ios/)

HOW: Scripts look for brightness thresholds to detect grey keyboard background vs white key faces, then measure row heights, gaps, side margins. Reference screenshots: native_kb.png and whisnap_kb.png.

GOTCHA: Threshold matters a lot — white keys push average brightness above 245-250. Script uses column/row sampling, not full-region average. Script also gets confused by toolbar icons/text being detected as 'Row 1'.
