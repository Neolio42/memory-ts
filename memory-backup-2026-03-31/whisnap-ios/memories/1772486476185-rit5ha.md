PATTERN: Keyboard appearance must respond to the HOST APP's requested appearance, not just system dark mode.
WHY: Safari private browsing forces dark keyboard in light mode. Some apps override appearance. traitCollection.userInterfaceStyle is unreliable.
IMPLEMENTATION:
```swift
// In KeyboardView.swift
var keyboardAppearance: UIKeyboardAppearance = .default {
    didSet {
        guard oldValue != keyboardAppearance else { return }
        backgroundColor = keyboardBackgroundColor
        rebuildLayout()
    }
}
private var isDarkMode: Bool {
    return keyboardAppearance == .dark || keyboardAppearance == .alert
}

// In KeyboardViewController.swift
override func textDidChange(_ textInput: UITextInput?) {
    super.textDidChange(textInput)
    let appearance = self.textDocumentProxy.keyboardAppearance ?? .default
    keyboardView.keyboardAppearance = appearance
}
```
Then use `isDarkMode` in all color computations instead of trait collection.
