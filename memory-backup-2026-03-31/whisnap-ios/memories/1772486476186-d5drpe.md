FACT: Whisnap iOS app with a keyboard extension that provides voice transcription directly in any text field.
ARCHITECTURE:
- Main app: nedas.Whisnap-IOS
- Keyboard extension: nedas.Whisnap-IOS.WhisnapKeyboard
- Voice relay flow: mic tap → check relay connection → if no relay, open whisnap-ios://relay URL scheme → main app handles transcription and pastes back
- Full Access required for relay
KEY FILES:
  - WhisnapKeyboard/KeyboardViewController.swift — UIInputViewController subclass
  - WhisnapKeyboard/KeyboardView.swift — Full custom keyboard UI
- The toolbar (top bar) replaces the system suggestion bar — shows Whisnap branding + mic button
- Globe key calls handleGlobe() which calls advanceToNextInputMode()
