SYMPTOM: State lost when switching tabs, stale transcripts, broken observation, search results reset unexpectedly.

CAUSE: @State creates a plain struct value. SwiftUI recreates views when they're re-rendered. ViewModels created with @State get destroyed and re-initialized on tab switch or parent re-render.

FIX:
```swift
// Before (BROKEN):
@State private var vm = RecordingViewModel()
@State private var vm = HistoryViewModel()
@State private var vm = SettingsViewModel()

// After (CORRECT):
@StateObject private var vm = RecordingViewModel()
@StateObject private var vm = HistoryViewModel()
@StateObject private var vm = SettingsViewModel()
```
ViewModels must inherit from ObservableObject for @StateObject.

FILES: RecordingView.swift:36, HistoryView.swift:13, SettingsView.swift:11

PREVENT: Never use @State for reference-type objects. @State is for value types (strings, ints, structs). @StateObject is for ObservableObject classes where the view owns the lifecycle.
