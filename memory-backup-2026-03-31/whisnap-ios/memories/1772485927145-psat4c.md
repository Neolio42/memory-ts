DEBUG
SYMPTOM: Startup shows 401 errors, WebSocket disconnect calls, RecordingView cleanup logs even when not recording
CAUSES + FIXES:
1. MonitoringService.init() called initializeHealthChecks() immediately on launch
   FIX: Added 2-second delay before performHealthChecks()
   FILE: Whisnap-IOS/App/Services/MonitoringService.swift
2. RecordingView.viewOnDisappear() called vm.reset() unconditionally — fired on every TabView tab switch
   FIX: Guard reset to only fire when status == .completed || status == .error
   FILE: Whisnap-IOS/App/Views/RecordingView.swift
REMAINING: The 401 error source may be stale/expired token scenario — APIClient has auth guard but may still attempt connection if token exists but is expired
