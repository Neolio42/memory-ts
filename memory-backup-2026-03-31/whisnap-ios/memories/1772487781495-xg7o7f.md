PATTERN: After all Swift files are created on disk, these manual Xcode steps are required:
1. Create keyboard extension target: File > New > Target > Custom Keyboard Extension, name WhisnapKeyboard
2. Add target membership to 6 shared files (check WhisnapKeyboard in File Inspector):
   - App/Data/KeychainManager.swift
   - Shared/API/Endpoints.swift, WebSocketModels.swift, WebSocketClient.swift
   - Shared/Models/Settings.swift, TranscriptionConfig.swift
3. Add capabilities to WhisnapKeyboard target (Signing & Capabilities):
   - App Groups: group.com.whisnap.app
   - Keychain Sharing: com.whisnap.shared
4. Verify CODE_SIGN_ENTITLEMENTS = WhisnapKeyboard/WhisnapKeyboard.entitlements in Build Settings
NOTE: Main app (Whisnap-IOS) needs same App Groups + Keychain Sharing capabilities
