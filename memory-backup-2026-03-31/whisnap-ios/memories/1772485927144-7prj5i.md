DEBUG
SYMPTOM: Voice strip appears completely unresponsive to taps — user taps but nothing happens
CAUSE: UILongPressGestureRecognizer with minimumPressDuration=0 fires immediately on touch down, consuming the touch event before UITapGestureRecognizer can recognize a tap. Even with cancelsTouchesInView=false, the long press wins.
FIX:
- Remove UITapGestureRecognizer entirely
- Keep only UILongPressGestureRecognizer with minimumPressDuration=0.05
- On .began: visual press-down animation (scale 0.97x, alpha 0.7)
- On .ended: check gesture.location(in: view) bounds, then call delegate and haptic
- On .cancelled/.failed: restore visual state
PREVENT: Never use minimumPressDuration=0 on long press when tap recognition is needed on same view
