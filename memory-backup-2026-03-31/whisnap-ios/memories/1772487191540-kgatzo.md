WHAT: How keyboard handles mic tap with the new Relay architecture.

WHERE: WhisnapKeyboard/KeyboardViewController.swift

FLOW:
```swift
func keyboardViewDidTapMic(_ view: KeyboardView) {
    guard !state.isBusy else { return }
    guard KeychainManager.isAuthenticated else { ... }
    if hasActiveRelay() {
        startRecording()    // reads chunks from App Group, streams to WebSocket
    } else {
        openAppForRelay()   // opens whisnap-ios://relay via extensionContext
    }
}
```

KEY METHODS:
- hasActiveRelay(): reads UserDefaults(suiteName:) → checks relayActive Bool + relayExpiry Date
- openAppForRelay(): extensionContext?.open(URL("whisnap-ios://relay"))
- startRecording(): creates KeyboardTranscriptionService, shows RecordingOverlayView
- stopRecording(): calls service.stopRecording { transcript in textDocumentProxy.insertText(transcript) }

OVERLAY: RecordingOverlayView replaces keyboard view during recording (waveform + transcript + stop button)

URL HANDLING: whisnap-ios://relay → Whisnap_IOSApp → .keyboardRequestedRelay notification → ContentView presents RelayView as .fullScreenCover
