DEBUG
SYMPTOM: Cloud sync succeeded (242 items fetched and inserted) but HistoryView showed nothing
CAUSE: @State private var isLoading = true in HistoryView. This was set to true in init but never set to false after data loaded. The view showed a permanent loading spinner.
FIX: Added isLoading = false in .onAppear after the viewModel is created/accessed
PREVENT: Always verify that every true-initializing loading state has a corresponding false assignment on all code paths
