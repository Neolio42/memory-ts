TECHNICAL
WHAT: VoiceStripState enum drives the voice strip UI in the keyboard extension
WHERE: WhisnapKeyboard/KeyboardView.swift (VoiceStripState enum + voiceStrip UI), KeyboardViewController.swift (refreshVoiceStrip + keyboardViewDidTapMic)
HOW:
- .noAuth: shows 'Sign in to Whisnap' + chevron → tapping calls openApp() [currently fails silently]
- .noRelay: shows 'Enable Voice Relay' + chevron → tapping calls openApp(path: 'relay')
- .ready: shows 'Tap to dictate' → tapping starts recording with audio backfill
refreshVoiceStrip() checks:
1. KeychainManager.isAuthenticated (may fail if keychain group mismatch — see critical unresolved)
2. hasActiveRelay() — reads UserDefaults relayActive + relayExpiry
WHEN REFRESHED: viewWillAppear only — not reactive to relay changes while keyboard is shown
GOTCHA: After user enables relay in Settings, keyboard must be dismissed and reshown for state to refresh
