SYMPTOM: Main app took forever to load — console logs didn't even appear. Felt frozen.
CAUSE: AuthService.init() called clearKeychainOnFreshInstall() + checkAuthenticationStatus() SYNCHRONOUSLY — these do Keychain reads (SecItemCopyMatching, ~100-500ms each) and were triggered by ContentView's @ObservedObject during SwiftUI view creation. MonitoringService health checks used Task{} which inherits @MainActor context.
FIX:
1. AuthService.init() — move slow keychain ops into Task { @MainActor [weak self] in ... }
2. MonitoringService.init() — change Task{} to Task.detached(priority: .utility)
3. Whisnap_IOSApp.initializeServices() — wrap MonitoringService.shared in Task.detached block
PREVENT: Any @ObservedObject or @StateObject singleton init that does I/O (Keychain, disk, network) will block app launch. Always defer to Task or background queue.
