SYMPTOM: Fatal error: SWIFT TASK CONTINUATION MISUSE: authenticate() tried to resume its continuation more than once

CAUSE: ASWebAuthenticationSession's completion handler fires twice on cancellation — once for the cancel event, once during teardown cleanup. CheckedContinuation crashes if resumed more than once.

FIX:
```swift
func authenticate(url: URL, callbackScheme: String) async throws -> URL {
    var didResume = false
    return try await withCheckedThrowingContinuation { continuation in
        let session = ASWebAuthenticationSession(url: url, callbackURLScheme: callbackScheme) { url, error in
            guard !didResume else { return }  // ← Guard is the fix
            didResume = true
            if let error = error {
                continuation.resume(throwing: error)
            } else if let url = url {
                continuation.resume(returning: url)
            }
        }
        // ...
    }
}
```

PREVENT: Any URLSession or system callback that might fire multiple times needs this guard before any continuation resume call.
