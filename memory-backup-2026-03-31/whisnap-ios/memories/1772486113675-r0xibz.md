FACT: User communicates with minimal words and maximum directness. Uses profanity ('this is trash', 'takes fucking forever') when frustrated with quality. Does not want explanations they didn't ask for.
CONTEXT: Running iterative audit-fix cycles on a complex iOS app. High quality bar.
AFFECTS:
- Run 3 auditors IN PARALLEL, all FOREGROUND — never background
- Start fixing immediately after audit results, don't ask 'should I fix these?'
- When user says 'audit again', launch auditors immediately with no preamble
- Don't pad responses with reassurances or verbose explanations
- Be decisive — make reasonable technical choices without asking
- User corrects mistakes bluntly; take the correction and fix immediately
