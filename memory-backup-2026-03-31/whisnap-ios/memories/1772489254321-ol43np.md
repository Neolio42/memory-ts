SYMPTOM: App freezes completely on launch or when navigating to Settings tab. No crash, just frozen UI. Settings.load() was calling semaphore.wait() on the main thread while a Task { loadedSettings = await actor.load(); semaphore.signal() } needed the main thread to run.

CAUSE: When SWIFT_DEFAULT_ACTOR_ISOLATION=MainActor is set in project build settings, all unstructured Tasks inherit @MainActor. The Task trying to signal the semaphore needed the main thread, but main thread was blocked by semaphore.wait(). Permanent deadlock.

FIX: Replace DispatchSemaphore+Task bridge with direct synchronous read:
```swift
static func load() -> Settings {
    guard let data = userDefaults?.data(forKey: userDefaultsKey),
          let settings = try? JSONDecoder().decode(Settings.self, from: data) else {
        return Settings.default
    }
    return settings.validated()
}
```

PREVENT: With SWIFT_DEFAULT_ACTOR_ISOLATION=MainActor, NEVER use DispatchSemaphore, sync wait patterns, or keychainQueue.sync from any context. Check project.pbxproj for this setting before any new async bridging code.
