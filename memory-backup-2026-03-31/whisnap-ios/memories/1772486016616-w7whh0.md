TECHNICAL:
WHAT: Three critical concurrency patterns fixed across the codebase

1. ToggleLock exception safety (RecordingView.swift)
   HOW: Replace explicit unlock with defer:
   ```swift
   guard await toggleLock.tryLock() else { return }
   defer { Task { await toggleLock.unlock() } }
   // no explicit unlock needed
   ```
   WHY: Early returns or thrown errors would skip unlock, deadlocking subsequent taps

2. AuthService token refresh dedup (AuthService.swift)
   HOW: Store shared Task<Void,Error>? — concurrent calls await same task:
   ```swift
   private var refreshTask: Task<Void, Error>?
   func refreshTokens() async throws {
       if let existing = refreshTask { try await existing.value; return }
       let task = Task { try await _doRefresh() }
       refreshTask = task
       defer { refreshTask = nil }
       try await task.value
   }
   ```
   WHY: Without dedup, concurrent refresh triggers multiple server requests, keychain race

3. WebSocket decode tolerance (WebSocketClient.swift)
   HOW: Track consecutiveDecodeFailures, only disconnect after 3+:
   ```swift
   consecutiveDecodeFailures = 0 // on success
   // on failure:
   consecutiveDecodeFailures += 1
   if consecutiveDecodeFailures >= 3 { disconnect() }
   ```
   WHY: Single malformed server message was killing entire session

GOTCHA: Token expiry buffer is now 120s (was 600s). Proactive refresh in CloudTranscriptionService checks 300s ahead — total effective buffer ~7 min.
