WHAT: Rewrote KeyboardView.swift entirely. Replaced floating voice strip with flat edge-to-edge toolbar. Height constraint is device-scaled, not a single constant.
LAYOUT:
- Top toolbar (44pt fixed): waveform SF Symbol + 'Whisnap' label on left; status text center-right; blue circular mic button (32x32) on right
- Key rows: UIStackView with .fillEqually distribution — rows auto-size to fill remaining height. No hardcoded keyHeight.
DEVICE-SCALED HEIGHT (KeyboardViewController):
  screenHeight <= 667 (SE, 8) → kbHeight = 260
  screenHeight <= 812 (X, 13 mini) → kbHeight = 271
  screenHeight <= 896 (14, 15) → kbHeight = 291
  else (15 Pro Max, 16+) → kbHeight = 301
  Priority: UILayoutPriority(999) — system can still adjust
CRITICAL FIX — container leak: rebuildLayout() MUST call keysContainer?.removeFromSuperview() before creating new container. Track container with private var keysContainer: UIStackView?
SPACING: rowSpacing=6, keySpacing=6, keyCornerRadius=5, sideInset=3, bottomInset=4
GOTCHA: Removing height constraint entirely causes fillEqually to divide zero height → Auto Layout thrash → app appears frozen.
