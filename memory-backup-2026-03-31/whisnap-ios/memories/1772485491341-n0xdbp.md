WHAT: WhisnapKeyboard redesigned to have a prominent voice input strip above QWERTY rows
WHERE: KeyboardView.swift, KeyboardViewController.swift
HOW:
  VoiceStripState enum: .ready / .noAuth / .noRelay
  voiceStripState didSet calls updateVoiceStrip() which sets label text + mic icon color
  Bottom row: [123 | Globe | Space | Return] — mic removed
  Strip height ~44pt, tappable, delegates to keyboardViewDidTapMic
  KeyboardViewController sets voiceStripState based on auth + relay.isActive
WHY: Bottom-row mic was tiny, hard to find, disabled silently. Strip is obvious.
DEEP LINK: extensionContext?.open(url:) is unreliable from keyboard extensions — removed. Instead show error toast: 'Enable Voice Relay in Whisnap first'
