INSIGHT: Three separate audit failures in relay toggle implementation
BEFORE: usingRelay flag was set at startRecording() but never re-checked; relay could die while recording leaving a zombie session with no audio. Toggle used try? silently. reset() didn't nil callbacks.
AFTER:
  1. setupRelayMonitoring() — Combine subscription on relayService.$isActive → auto-stopRecording() if relay dies and usingRelay==true
  2. Toggle binding uses do/catch → shows alert on failure (not try?)
  3. reset() nils relayService.onAudioChunk AND audioCaptureService.onAudioBuffer AND sets usingRelay=false
  4. Toggle has .disabled(transcriptionService.status.isRecording)
IMPLICATIONS: Every new audio source path needs: (a) mid-session death handler, (b) error surfacing, (c) cleanup in reset()
