SYMPTOM: Replaced solid background color with UIVisualEffectView(UIBlurEffect(style: .systemChromeMaterial)) — entire keyboard appears white.
CAUSE: Keyboard extension host view behind the keyboard is white/transparent. The blur effect has no colored content to blur, so it renders as plain white.
FIX: Use solid backgroundColor. The correct value is: light mode = #E3E4E8 / dark = #262626.
REJECTED: UIVisualEffectView, UIGlassEffect (#available iOS 26), backgroundColor = .clear — all produce white keyboard in extension context.
