SYMPTOM: Console warning: '-[UIInputViewController needsInputModeSwitchKey] was called before a connection was established to the host application. This will produce an inaccurate result.'
CAUSE: UIInputViewController.needsInputModeSwitchKey is called during viewDidLoad when the host app connection isn't established yet.
FIX: Move any call to needsInputModeSwitchKey (and any layout that depends on it, like globe key visibility) to viewWillAppear or later in the lifecycle.
PREVENT: In keyboard extensions, host-dependent properties (needsInputModeSwitchKey, textDocumentProxy features) should only be accessed after viewWillAppear.
