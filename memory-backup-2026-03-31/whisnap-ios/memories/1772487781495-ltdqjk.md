PATTERN: When creating a Custom Keyboard Extension target in Xcode (File > New > Target), Xcode auto-generates a default KeyboardViewController.swift and Info.plist that OVERWRITE any existing files with the same names.
WHEN: Every time a new keyboard extension target is created in Xcode.
WHY: Xcode's template system doesn't check for existing files — it just writes them.
FIX: After creating the target, immediately check if your custom files were overwritten (look for Xcode's boilerplate 'override var inputView' in KeyboardViewController.swift). If overwritten, restore from your implementation or version control.
IMPORTANT: The auto-generated Info.plist has RequestsOpenAccess = false and IsASCIICapable = false — both must be true for a functional keyboard with network + mic access.
