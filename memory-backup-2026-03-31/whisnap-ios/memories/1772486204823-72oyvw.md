PRINCIPLE: iOS keyboard extensions have strict sandbox limits
KEY LIMITS:
  - No microphone access (AVAudioEngine forbidden)
  - ~50MB memory limit
  - No background execution
  - UIKit only (no SwiftUI)
  - UIApplication.shared restricted (use ObjC runtime trick)
IMPLICATION FOR MIC: Keyboard CANNOT record audio directly. Must use relay:
  Main app (has mic permission) → captures audio → writes to App Group → keyboard reads
IMPLICATION FOR API: Keyboard CAN use URLSession and WebSocket (Network.framework)
SHARED RESOURCES (App Group 'group.com.whisnap.ios'):
  - UserDefaults(suiteName:) for relay state flags
  - Shared Keychain (AccessGroup) for JWT tokens
  - FileManager containerURL(forSecurityApplicationGroupIdentifier:) for PCM chunk files
