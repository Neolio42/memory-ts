SYMPTOM: Keyboard flashes blank/white when switching to Whisnap keyboard because showGlobe setter triggers rebuildLayout.

CAUSE: Original implementation called rebuildLayout() in the showGlobe didSet, tearing down and rebuilding all rows.

FIX in KeyboardView.swift:
```swift
// Store reference at class level
private weak var globeButton: UIButton?

var showGlobe: Bool = true {
    didSet {
        // Just toggle visibility — never rebuild
        globeButton?.isHidden = !showGlobe
    }
}

// In makeBottomRow: always create globe button, store reference
let globe = makeKey(title: "", isSpecial: true)
globe.setImage(UIImage(systemName: "globe"), for: .normal)
globe.isHidden = !showGlobe  // initial state
globeButton = globe
row.addArrangedSubview(globe)
```

PREVENT: Any property that affects a single button should toggle that button, not rebuild the whole layout.
