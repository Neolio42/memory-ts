INSIGHT: The iOS native suggestion bar (75pt tall) is rendered by the system ABOVE the keyboard extension — it is NOT included in the extension's intrinsicContentSize/frame height. We were incorrectly including it, making our grey area ~60pt too tall.

AFTER: Frame = toolbar(44pt) + 4×key(45pt) + 3×gap(11pt) + bottom(4pt) = 261pt
BEFORE: Frame was 313pt (included ghost 75pt for suggestion bar we don't have)

IMPLICATIONS: Never add the suggestion bar height to keyboard extension frame. Our toolbar REPLACES the suggestion bar slot visually but sits inside the extension frame at 44pt, not 75pt.
