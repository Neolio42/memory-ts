BREAKTHROUGH:
  INSIGHT: FluidAudio SDK (latest: v0.12.1, we pin from: '0.7.9') has a documented ManualModelLoading.md path. Key APIs:
    - AsrModels.load(from: URL, configuration: AsrConfiguration?, version: AsrModelVersion) — loads from local directory, NO network download
    - AsrModels.modelsExist(at: URL) -> Bool — checks all required files present
    - AsrModels.defaultConfiguration() -> AsrConfiguration — default CoreML compute config
  BEFORE: We called downloadAndLoad() — atomic, uncancellable, no progress, SDK manages everything
  AFTER: We can download files ourselves from HuggingFace with URLSession (real progress, real cancel, pause/resume), then call load(from:) to compile/load from local path
  IMPLICATIONS:
    1. FluidAudio models can use the same Manifest download system as Whisper/sherpa parakeet models
    2. Cancel, pause, resume all work via existing CancellationToken infrastructure
    3. Real byte-level progress instead of 5% simulation every 3 seconds
    4. Download and load become separate operations
  DOCS: github.com/FluidInference/FluidAudio/blob/main/Documentation/ASR/ManualModelLoading.md
  REQUIRED FILES: Preprocessor.mlmodelc, Encoder.mlmodelc, Decoder.mlmodelc, JointDecision.mlmodelc, parakeet_vocab.json
  NOTE: HuggingFace file sizes from tree API are Git LFS pointer sizes (~485 bytes), NOT actual file sizes. Need HEAD requests on LFS download URLs to get real sizes.
