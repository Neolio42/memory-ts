SYMPTOM: Holding FN (push-to-talk) then pressing Space caused weird behavior - recording cancelled on Space, then restarted on FN release.

CAUSE: Two compounding bugs:
1. Toggle keybind handler (service.rs ~line 1199) fired during PushToTalkActive state - Space press during FN hold called toggle_live_transcription which stopped the active recording
2. stop_recording() blindly delegated to toggle_live_transcription - when called while Idle, it STARTED a new recording instead of being a no-op

FIX:
1. Toggle keybind handler now checks coordinator state and ignores Space presses when push-to-talk or command mode is already active
2. stop_recording() now checks if actually recording before delegating to toggle

PREVENT: Any new hotkey handler touching recording state must check coordinator state first. stop_recording should never start recording.
