WHAT: Whisnap stores each recording as a folder under ~/Documents/whisnap/recordings/ containing audio segments with JSON metadata
WHERE: ~/Documents/whisnap/recordings/
HOW: Each segment's metadata has an end_ms field (milliseconds from recording start) which can be used to compute duration. Sum max(end_ms) per recording for total talk time.
WHY: No top-level 'duration' field exists — duration must be derived from segment timing data
GOTCHA: The history store (in-app) does not persist duration directly; all duration math must be done from raw segment files on disk
