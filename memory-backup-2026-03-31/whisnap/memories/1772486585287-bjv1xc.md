WHAT: bundleId is the single key that activates the entire context learning system

THREE SYSTEMS IT ENABLES:
1. Per-app formatting — email structure for com.apple.mail, concise chat for com.tinyspeck.slackmacgap, code comments for com.microsoft.VSCode
2. Vocab scoping — terms learned in one app (e.g. 'kubectl' in Terminal) don't pollute other apps (e.g. Mail)
3. Style fingerprinting — after 10 transcriptions for a given bundleId, analyze raw speech patterns and build a per-user, per-app style profile

SOURCE: NSWorkspace.shared.frontmostApplication?.bundleIdentifier
MAX LENGTH: 256 chars (truncated server-side)

GOTCHA: All three systems are server-side — the client only sends bundleId; the server handles all learning/application logic
