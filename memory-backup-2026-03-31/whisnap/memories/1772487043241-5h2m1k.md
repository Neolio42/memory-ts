WORKFLOW: This project has a PostToolUse:Edit hook that runs tsc --noEmit after every single file edit. TypeScript's strict no-unused-variables rule (TS6133) will block continuation if you import something or declare a variable without immediately using it.
PATTERN: When adding a new import + usage (e.g., Trash2 icon + delete button JSX), do it in a SINGLE edit that adds both the import AND the usage. Don't split into 'add import' then 'add usage' — the first edit will fail.
SAME FOR PROPS: When adding a new prop to a component interface, add the destructuring AND the usage in the same edit.
SAME FOR EVENT LISTENERS: When adding to an interface type definition, also add the implementation in the same edit.
WORKAROUND IF SPLIT IS NECESSARY: Add a dummy comment-usage or restructure to add both simultaneously.
