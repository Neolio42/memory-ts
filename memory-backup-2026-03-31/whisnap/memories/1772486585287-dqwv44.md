DECISION: Collect appContext fields via AXUIElement where accessibility is granted, silently skip/null individual fields when not accessible

OPTIONS: (1) Require accessibility permission and block if missing, (2) Collect everything available via AX, degrade gracefully, (3) Only collect windowTitle via NSWorkspace (no AX needed)

REASONING: User explicitly confirmed: use accessibility for everything available, gracefully fall back if not granted. No new permissions should be requested.

APPLICATION:
- windowTitle: available from NSWorkspace without AX (easy, always send)
- inputFieldContent: requires AX — send only if AXIsProcessTrusted()
- threadContext: requires AX — send only if AXIsProcessTrusted()
- fileLanguage: requires AX (or editor extension) — send only when available
- cursorContext: requires AX — send only when available
- App already has check_fn_accessibility() calling AXIsProcessTrusted()

REVISIT WHEN: If user wants to request accessibility permission proactively
