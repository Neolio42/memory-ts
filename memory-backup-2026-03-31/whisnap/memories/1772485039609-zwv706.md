INSIGHT: The 300ms threshold exists to prevent macOS language switching interference when bare FN is pressed alone. macOS interprets a quick tap of FN as a language switch command.

RULES:
- Bare FN (push-to-talk or toggle): needs 300ms threshold. Hold past 300ms to activate; quick tap does nothing. This prevents accidental language switches.
- FN+key combo (e.g., FN+Space): instant. Key down → action starts, key up → action stops. NO threshold needed because macOS already knows it's not a language switch when another key is pressed simultaneously.

APPLICATION TO ACTIONS:
- FN+Space as push-to-talk: instant on/off with key down/up
- FN+Space as toggle: instant toggle on key down
- Bare FN as toggle: hold 300ms to start, hold 300ms again to stop
- Bare FN as push-to-talk: hold 300ms to start, release to stop

This distinction is critical when implementing multi-action FN support — don't apply the 300ms delay to combo keybinds.
