SYMPTOM: cargo check error E0425 'delete_model not found in scope' even though it exists in commands/models.rs
CAUSE: lib.rs uses an explicit named import like: use commands::models::{download_model, cancel_download, ...} — NOT a glob import. New commands must be added to this list.
FIX: Add the new command name to the explicit import in lib.rs, AND add it to both invoke_handler![] blocks
WHERE: src-tauri/src/lib.rs — search for 'use commands::models' or 'use crate::commands'
PATTERN: lib.rs has TWO invoke_handler![] blocks (one for mobile, one for desktop, or similar split) — add new command to BOTH
