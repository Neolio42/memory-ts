SYMPTOM: Download appeared to not start, cancel gave 'No active download found'
CAUSE: SdkManaged branch emitted wrong event formats and never registered with DownloadManager

FRONTEND EVENT CONTRACT (src/services/tauri.ts):
```typescript
// Progress event
listen<{ model_id: string, downloaded_bytes: number, total_bytes: number }>('model_download_progress', ...)

// Completion — payload is just the model_id string, NOT an object
listen<string>('model_download_completed', ...)

// Error
listen<{ model_id: string, error: string }>('model_download_error', ...)

// Cancelled — payload is just the model_id string
listen<string>('model_download_cancelled', ...)
```

FIX: Changed SdkManaged emissions to match exactly. Note: model_download_completed (with 'd' at end) not model_download_complete.

CANCEL FIX: Must call download_manager.register_download(model_id, cancellation_token) — frontend calls cancel_model_download command which calls download_manager.cancel(model_id)
