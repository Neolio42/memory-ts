QUESTION: How to populate threadContext (email/chat reply content) and fileLanguage (code editor language) in AppContext?

CONTEXT: Both fields exist in the AppContext struct and the server supports them, but capture_frontmost_app_context() never sets them. They require app-specific logic.

BLOCKERS:
- threadContext: No generic AX attribute — would need bundle-ID-specific heuristics (e.g., Mail uses kAXDescription on focused cell, Slack would need web scraping)
- fileLanguage: Would need to check bundle ID (com.microsoft.VSCode, com.apple.dt.Xcode) and either read file extension from window title or use AX document URL

OPTIONS:
- Match on known bundle IDs and use app-specific AX paths
- For VS Code specifically: read the window title which often contains file extension
- Leave as None until server-side usage justifies the complexity
