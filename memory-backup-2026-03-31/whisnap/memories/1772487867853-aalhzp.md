WHAT: Runtime routing between whisper/sherpa/fluidaudio backends based on selected model's backend_id

WHERE: src-tauri/src/features/transcription/components/transcribers/dynamic_transcriber.rs

HOW:
1. Gets model_id from settings.model.model_id
2. Calls model_loader.model_file_service.get_backend_id_by_model_id(&model_id)
3. Match on backend_id: "whisper" → WhisperTranscriber, "fluidaudio" → FluidAudioTranscriber, "parakeet" (feature sherpa) → ParakeetTranscriber

REQUIRED IMPORT: `use crate::features::transcription::traits::ModelFileServiceTrait;` (gotcha from Phase 1)

BACKEND_ID SOURCE: Set in model_registry.rs registry_model_to_definition() from category_info.backend. The "fluidaudio" category in models.json has `"backend": "fluidaudio"` → ModelFormat::SdkManaged + backend_id: "fluidaudio".

GOTCHA: Orchestrator is built once at startup — this runtime routing is why DynamicTranscriber exists (orchestrator can't be rebuilt per-model)
