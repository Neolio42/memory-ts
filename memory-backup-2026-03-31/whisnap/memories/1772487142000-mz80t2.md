TECHNICAL: Dead type variants removed after sherpa cleanup.

WHAT: Three enum variants removed that represented ONNX multi-file model layouts:
- ModelManifestFormat::MultiFileOnnx → removed (manifest.rs)
- ModelFormat::MultiFileOnnx → removed (model_management/types.rs)
- ModelPath::MultiFile { encoder, decoder, joiner, tokens } → removed (inference/types.rs)

Also removed:
- FileType enum + infer_file_type() function (manifest.rs)
- create_parakeet_manifest() + create_parakeet_fp16_manifest() (manifest.rs)
- example_model_definitions() dead function (types.rs)

Current ManifestBuilder default: SingleFile (was MultiFileOnnx before)

Current valid ModelManifestFormat variants: SingleFile, CoreML, Archive
Current valid ModelFormat variants: SingleFile, Directory, Manifest
Current valid ModelPath variants: SingleFile(PathBuf), Directory(PathBuf), Remote { url, cache_path }

GOTCHA: No serde alias added for MultiFileOnnx → CoreML. If any user has old persisted manifests with format='MultiFileOnnx', deserialization will fail.
