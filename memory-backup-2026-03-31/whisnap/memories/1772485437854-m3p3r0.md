INSIGHT: All post-paste behavior monitoring uses only Accessibility (already granted).

PERMISSION MAP:
- CGEventTap (keyDown global) → Accessibility (NOT Input Monitoring)
- NSEvent.addGlobalMonitorForEvents → Accessibility
- AXUIElementCopyAttributeValue (text field value) → Accessibility
- AXObserverAddNotification (value changes) → Accessibility
- Input Monitoring permission only needed for IOHIDManager-based monitoring (not our approach)

DETECTION APPROACHES by complexity:
A. Keystroke counting (MVP): Count keys between paste and Enter. backspace/typing = edited. Low complexity.
B. AX value snapshot: Read focused element value after paste, re-read on Enter, diff. Medium complexity. Doesn't work in all apps (Electron limited).
C. AX value change observer: AXObserverAddNotification kAXValueChangedNotification. High complexity.

APP COMPATIBILITY GOTCHA: AX value reading doesn't work in all apps. Good for: native macOS, Slack, Messages. Bad for: some Electron apps, custom text fields. Terminal apps skipped already.

MVP CHOICE: Keystroke counting (A) - gives sent/edited/abandoned signal without reading any text content.
