MUST REMOVE for App Store:
- tauri-plugin-updater (lib.rs:152, tauri.conf.json:60-68) - App Store handles updates
- CLI install via osascript (cli.rs:669-694, 722-732) - can't run with admin privs or write to /usr/local/bin
- macOSPrivateApi: true (tauri.conf.json:14, Cargo.toml:123) - Apple rejects private API usage

MUST ADAPT for App Store:
- Launch at login (features/system_integration/service.rs:111-246) - writes plist to ~/Library/LaunchAgents/, must migrate to SMAppService (macOS 13+)
- Recordings in ~/Documents (features/directory_management/service.rs:56-58) - must use app container or user-selected entitlement
- Logs in ~/Library/Logs (core/logging.rs:226-228) - must use Tauri app_data_dir()
- Subprocess calls (commands/device.rs:69-107): scutil/hostname/sw_vers - replace with NSHost/ProcessInfo

COMPATIBLE as-is: microphone, clipboard, network, deep links, model storage, NSWorkspace, notifications
