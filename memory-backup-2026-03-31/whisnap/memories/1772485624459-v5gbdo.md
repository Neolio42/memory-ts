WORKFLOW: `npm run tauri:context` is the debug script for app context capture feature.

WHEN: Use when developing/testing bundleId, appContext, window title, input field capture.

WHY: `RUST_LOG=off,system::integration=debug,transcription=info tauri dev` — shows debug from system::integration module (where capture_frontmost_app_context lives) and info from transcription pipeline.

Also relevant:
- `npm run tauri:cloud` — broader cloud transcription logs
- Script added to package.json alongside other tauri:* scripts
