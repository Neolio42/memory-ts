DEBUG:
  SYMPTOM: 3.5 second gap between 'Permission granted' and 'Model validation successful' on every FN key press
  CAUSE: check_model_exists only checked user_model_path and bundled_model_path — no SdkManaged arm. resolve_model_robust got (false, None) → retried with exponential backoff: 500ms + 1s + 2s = 3.5s total (max_retries=3, base_delay=500ms, backoff_multiplier=2.0, |_| true makes ALL errors retryable)
  FIX: Added SdkManaged arm to check_model_exists that checks cache_path.join(f).exists() for all required_files. Returns (true, Some(cache_path)) when all present.
  PREVENT: When adding new ModelFormat variants, always add matching arm to check_model_exists in service.rs. Also fix the fallback warning: 'Using fallback model: parakeet-tdt-0.6b-v3-coreml, using parakeet-tdt-0.6b-v3-coreml instead' — this was caused by the same issue (direct resolution failing, falling to slower fallback path).
