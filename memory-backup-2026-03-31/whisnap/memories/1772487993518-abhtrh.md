TECHNICAL:
  WHAT: Frontend event listeners in tauri.ts are typed for specific payload formats per event
  WHERE: src/services/tauri.ts event listener types
  HOW (correct payload formats):
    model_download_progress   → { model_id: string, downloaded_bytes: number, total_bytes: number }
    model_download_completed  → string (bare model_id, note: 'completed' not 'complete')
    model_download_error      → { model_id: string, error: string }
    model_download_cancelled  → string (bare model_id)
    model_download_paused     → string (bare model_id)
    model_download_resumed    → string (bare model_id)
  GOTCHA: The Rust emit calls for cancelled/paused/resumed must use &model_id (bare str ref), NOT serde_json::json!({"model_id": ...}). Getting this wrong causes silent failures — the frontend handler receives an unexpected object type and may silently ignore or crash.
  RUST PATTERN:
    // CORRECT:
    let _ = app_handle.emit("model_download_cancelled", &model_id_clone);
    // WRONG:
    let _ = app_handle.emit("model_download_cancelled", serde_json::json!({"model_id": model_id_clone}));
