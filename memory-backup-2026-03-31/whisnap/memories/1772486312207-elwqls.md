PATTERN: Full audit of FN coordinator and hotkey system (post bug-fix)

VERIFIED WORKING:
- FN+Space quick tap (<300ms): toggle fires immediately via handle_shortcut_event, shortcut_fired flag prevents hold timer from also starting push-to-talk
- FN+Space double-tap: 300ms debounce in handle_recording_toggle prevents accidental double-presses within single FN hold
- Race between hold timer and Space press: tokio::select! is biased (events before timeouts), FN_SHORTCUT_FIRED flag prevents double-action
- Escape during FN+Space toggle recording: handled correctly, coordinator Idle state routes to cancel_recording
- Stopping state: toggle and stop both handle Stopping state safely

EDGE CASE (theoretical): If user has both non-FN push-to-talk (Alt+N) AND non-FN toggle (Alt+Space), using both simultaneously could stop toggle-initiated recording. Niche scenario, not fixed.

OVERALL: System is solid after the two fixes applied in this session.
