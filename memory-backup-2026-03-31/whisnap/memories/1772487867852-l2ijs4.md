WHAT: New ModelFormat variant for SDK-managed model downloads (FluidAudio)

WHERE: src-tauri/src/features/model_management/types.rs
```rust
SdkManaged {
    sdk_version: String,
    cache_dir: String,      // absolute path to SDK cache dir
    required_files: Vec<String>,  // files that must exist to consider downloaded
}
```

STATUS CHECK (service.rs get_model_status): Iterates required_files, checks each Path::new(&cache_dir).join(f).exists(). Returns NotDownloaded if any missing, Downloaded (with virtual path) if all present.

DOWNLOAD FLOW (service.rs download_model):
1. Create CancellationToken
2. Emit model_download_progress with downloaded_bytes:0, total_bytes: model size
3. Spawn tokio task: select! between FluidAudioBridge::load_model() and cancel token
4. Background progress ticker: emits 5% increments every 3s up to 95%
5. Register with download_manager
6. On success: emit model_download_completed (just model_id STRING, not JSON)
7. On cancel: emit model_download_cancelled

GOTCHA: Pre-warm in manager.rs must actually call fluidaudio::load_model() — NOT skip — so model is ready for first transcription
