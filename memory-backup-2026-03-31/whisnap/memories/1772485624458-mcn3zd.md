WHAT: AppContext struct in types.rs for cloud transcription context. All fields optional with skip_serializing_if.

WHERE: src-tauri/src/features/inference/backends/cloud/types.rs

HOW:
```rust
#[derive(Debug, Clone, Serialize, Deserialize, Default)]
#[serde(rename_all = "camelCase")]
pub struct AppContext {
    #[serde(skip_serializing_if = "Option::is_none")]
    pub window_title: Option<String>,       // populated ✅
    #[serde(skip_serializing_if = "Option::is_none")]
    pub input_field_content: Option<String>, // populated ✅ (AX kAXValue)
    #[serde(skip_serializing_if = "Option::is_none")]
    pub thread_context: Option<String>,     // NOT populated ❌
    #[serde(skip_serializing_if = "Option::is_none")]
    pub file_language: Option<String>,      // NOT populated ❌
    #[serde(skip_serializing_if = "Option::is_none")]
    pub cursor_context: Option<String>,     // populated ✅ (AX kAXSelectedText)
}
```

WHY: Serializes to camelCase for JSON API (windowTitle, inputFieldContent, etc.). skip_serializing_if keeps payload minimal.

GOTCHA: thread_context (email reply content) and file_language (code editor language) require app-specific logic and are always None currently.
