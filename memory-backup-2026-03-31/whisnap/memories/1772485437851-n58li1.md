DECISION: Use a separate /v1/transcription-feedback endpoint (not the transcription endpoint) for post-paste behavioral feedback.

DECISION: Keep MVP to keystroke heuristics only - no text content in v1, avoids privacy complexity.

CONTRACT:
```
POST /v1/transcription-feedback
Authorization: Bearer <existing-jwt>
{
  "transcription_id": string,
  "action": "sent" | "edited" | "abandoned",
  "time_to_action_ms": number,
  "target_app_bundle_id": string,
  "key_count_before_send": number,
  "client_timestamp": string  // ISO 8601
}
Response: 202 Accepted
```

IMPLEMENTATION PLAN:
1. After paste completes in PasteHandler, start short-lived CGEventTap (2-5 second window)
2. Watch for Enter → action='sent', count other keystrokes for key_count_before_send
3. On timeout with no Enter → action='abandoned'
4. If keys typed before Enter → action='edited'
5. Fire-and-forget POST (don't block anything)

PERMISSIONS: Accessibility only (already requested). CGEventTap with AXIsProcessTrusted covers keystroke observation.

FUTURE V2: Re-read AXValue after Enter, diff against pasted text → actual edit content for model fine-tuning.
