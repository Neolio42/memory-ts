INSIGHT: When enumerating HuggingFace repos with Git LFS, the tree API returns pointer sizes (~485 bytes) for LFS-tracked files. This can cause false suspicion that small files are LFS pointers.
FOR FLUIDAUDIO: coremldata.bin files (~400-600 bytes) are genuinely that small — confirmed via HEAD requests on /resolve/main/ URLs which return real Content-Length. NOT LFS pointers.
ACTUAL LARGE FILES: weights/weight.bin inside each .mlmodelc directory (Encoder: 445MB, Decoder: 14-23MB, JointDecision: 3-12MB, Preprocessor: ~300-490KB)
PATTERN: To get real sizes from HuggingFace: use HEAD request on https://huggingface.co/{repo}/resolve/main/{path} — follows LFS redirects and returns actual Content-Length
COMMAND: curl -sI 'https://huggingface.co/{repo}/resolve/main/{file}' | grep content-length
