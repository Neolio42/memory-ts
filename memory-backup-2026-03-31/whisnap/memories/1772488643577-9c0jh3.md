WHAT: Auto-update uses tauri-plugin-updater v2.9.0. On startup (10s delay) and every 1hr poll, checks if configured interval (default 24h) has elapsed, then fetches update endpoint.

WHERE: src-tauri/tauri.conf.json (endpoint config), src/services/updater.service.ts (frontend logic)

HOW:
  Endpoint: GET https://{API_DOMAIN}/releases/update/{target}-{arch}/{current_version}?channel={channel}
  Header: X-Update-Channel: {channel}
  Response: JSON with version, notes, pub_date, platforms[].url (pre-signed S3/B2 URL), platforms[].signature

WHY: Pre-signed Backblaze B2 URLs mean binary downloads go direct to object storage, not through API server. Signature verified against minisign pubkey in tauri.conf.json.

GOTCHA: tauri.conf.json always contains staging domain in git. Build scripts must patch it. Rust-side updater uses the baked-in URL - VITE_API_DOMAIN only affects the TypeScript updater service, not the Rust plugin.
