TECHNICAL: Runtime transcription routing between Whisper and FluidAudio backends.

WHERE: src-tauri/src/features/transcription/components/transcribers/dynamic_transcriber.rs

HOW:
```rust
match backend_id.as_str() {
    #[cfg(feature = "fluidaudio")]
    "fluidaudio" => self.fluidaudio.transcribe(audio, correlation_id).await,
    "whisper" => self.whisper.transcribe(audio, correlation_id).await,
    _ => {
        warn!(target: "transcription::dynamic",
            backend_id = %backend_id,
            "Unknown or unavailable backend, falling back to Whisper"
        );
        self.whisper.transcribe(audio, correlation_id).await
    }
}
```

WHY: backend_id comes from the active model's registry entry (e.g. 'fluidaudio' for parakeet-tdt-0.6b-v3-coreml, 'whisper' for all whisper models). Fallback to whisper with warning prevents silent failures.

GOTCHA: When compiled without fluidaudio feature, 'fluidaudio' backend_id silently falls through to whisper — the warn log helps detect this misconfiguration.
