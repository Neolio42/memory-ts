WHAT: Three generations of Parakeet ONNX models with different capabilities and compatibility

HOW:
- v2 (0.6B): English-only, fully supported by sherpa-onnx HuggingFace repos (encoder.int8.onnx + decoder.int8.onnx + joiner.int8.onnx + tokens.txt)
- v3 (0.6B): Released Aug 14 2025, 25-language multilingual, ONNX conversion available at `istupakov/parakeet-tdt-0.6b-v3-onnx` on HuggingFace, BUT sherpa-onnx streaming for v3 requires architecture changes
- 1.1B: No confirmed ONNX export for production use

WHY: Use v2 for initial integration — it's battle-tested and works with existing sherpa-onnx model loading code. Add v3 as a follow-up once streaming architecture is understood.

GOTCHA: v3 multilingual model changes the decoding pipeline — don't assume drop-in replacement with v2 model files
