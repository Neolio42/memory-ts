Implemented a 'Hide Dock Icon' settings toggle for Whisnap (Tauri/macOS). The feature required direct Cocoa FFI rather than Tauri's AppHandle API, and a critical bug was found where `_debouncedSaveSettings` explicitly remaps every field before sending to backend, silently dropping any new setting not added to the mapping.
